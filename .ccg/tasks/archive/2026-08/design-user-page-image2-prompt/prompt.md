# Image 2 提示词：拼吧“我的”页面

请同时参考我上传的两张图片：①“拼吧”启动封面；②当前已经确认的“发现”页面。严格继承它们的视觉语言，设计微信小程序“拼吧”的“我的”页面高保真 UI 视觉稿。

画布为竖屏手机界面，比例 9:19.5，建议 1179×2556 px；只输出完整页面画布，不要手机外框、手持设备、环境背景或展示样机。页面为微信小程序沉浸式 custom navigation，顶部仅保留系统状态栏和右上角微信胶囊安全区，不出现原生页面标题栏，不出现“我的”大标题覆盖顶部。

品牌与风格：延续现有 3D 体素拼豆、isometric 3/4 俯视、柔和环境光、细腻接触阴影、轻微磨砂白卡片、温暖友好的澳门校园公益合乘氛围。全局背景使用极浅灰绿色 #F5F7F6，主色为翡翠绿 #16A36A，深色正文为 #1D2922，辅助灰为 #748078。司机相关信息可以少量使用低饱和雾霾蓝，但不能取代品牌绿。卡片为白色或极淡薄荷白，圆角 24–28 px，极轻柔阴影，边框几乎不可见。避免玻璃拟态过度、霓虹光、赛博朋克、高饱和渐变和商业网约车质感。

页面信息结构从上到下：

1. 顶部个人资料卡：位于胶囊安全区下方，左右留白一致。左侧放一个精致的体素学生头像，风格与现有乘客头像完全一致，头像置于柔和浅绿圆角底座中；中间预留两行真实文字区域，第一行为用户昵称，第二行为“澳门 / 已满18岁 / 资料状态”等辅助信息；右侧放小型箭头和一枚低调的翡翠绿品牌拼图装饰。资料卡不要做成大面积 Hero，不超过页面首屏高度的 18%。

2. 身份视图分段控件：紧接资料卡，两个等宽选项，代表“我的拼车”和“司机任务”。左侧乘客视图为当前选中态：白色或浅薄荷底、翡翠绿强调、细腻内阴影；右侧司机视图为未选中态：浅灰底、低饱和蓝灰提示。控件高度满足 44 px 触控区域，层级清楚但不过度抢眼。

3. 三列数据概览卡：一张紧凑的白色圆角卡内部等分三列，分别预留“待处理、我的发布、我的参与”的数字与标签位置。每列上方可使用极小体素图标：绿色提示点、橙色拼图、灰绿色双人头像；中间用极细分隔线。数据概览必须简洁，不能像金融仪表盘。

4. 待处理区域：小型分区标题下展示一张紧凑任务卡。左侧为绿色状态点或微型体素拼图，中部预留两行文字，右侧为轻量动作提示和箭头。卡片表达“有人申请加入 / 行程状态变化”这类校园合乘通知，不使用商业订单、金额或支付图标。

5. 行程列表切换：一条浅灰绿胶囊分段控件，代表“我的发布”和“我的参与”，当前选中项为白色浮层与翡翠绿文字。下方展示 1–2 张我的行程卡片，卡片视觉必须继承发现页已确认的“上方信息区 + 下方体素视觉带”结构：上方完整预留路线名称、时间窗、人数和状态徽标；下方左侧放体素乘客头像与灰色空位头像，右侧放绿色或蓝色起点方块、CSS 风格虚线、绿色合乘小车、凼仔或金龙校区微型建筑，右下角仅有细小箭头，整卡可点击，不要独立大按钮。

6. 底部微信原生 TabBar：白色背景，三个均匀分布的体素图标，依次代表发现、发布、我的。“我的”为当前激活态，使用翡翠绿色体素小人；发现和发布均为中性灰色未激活态。图标几何与当前发现页素材保持一致，底部安全区完整，TabBar 不使用悬浮大按钮。

构图要求：页面左右边距统一约 16 px，模块间距 12–16 px，首屏至少能看到个人资料卡、身份切换、数据概览、待处理卡和第一张行程卡的上半部分。视觉密度适中，不能因为装饰插画牺牲功能信息。所有体素图案只能作为辅助视觉，不遮挡文字安全区。320 px 小屏和系统大字号下仍应具有可伸缩空间，卡片不使用固定文本高度。

文字政策非常重要：不要生成任何可读中文、英文、数字、Logo 字母、乱码或伪文字。所有需要真实文字的位置只保留干净、规则、可后期覆盖的中性灰色文本占位线或完全留白；不要把文字烘焙进图片。不要生成“拼吧”“我的拼车”“司机任务”等真实字样。最终文字、数字、按钮标签和状态徽标将由微信小程序 WXML 单独渲染。

输出目标：一张可用于产品评审的高保真“我的”页面视觉稿，必须与现有启动封面和发现页看起来属于同一套产品、同一位设计师、同一套体素资产系统；精致、温暖、清爽、可信赖，突出校园互助而非商业出行。

负面约束：禁止真实照片、扁平矢量卡通、二次元、人物大头照、商业出租车标识、价格、钱包、支付、地图导航大图、霓虹、黑色背景、厚重渐变、超大标题、独立悬浮发布按钮、文字乱码、英文 Logo、过多绿色实心按钮、过密装饰、体素图案遮挡信息。
