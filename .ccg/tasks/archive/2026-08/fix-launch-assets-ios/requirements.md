# iPhone 启动页资源加载修复

## 现象

- iPhone 预览中启动覆盖层、深色承载卡和文字正常显示。
- 本地 WebP 封面、三维凹槽和立方体均未显示，因此看不到落块动画。
- 页面未卡死，说明组件挂载与 JS 时间轴仍在运行，故障集中在图片打包、路径或真机解码层。

## 目标

- 冷启动在 iPhone 真机稳定显示静态封面、透明凹槽和透明立方体动画。
- 不因弱网或云存储临时不可用导致启动页重新白屏。
- 保留约 5 秒时序、横向透视、深色承载卡和 Safe Area 布局。
- 如采用云存储，必须同时保留可靠的本地降级路径，并明确 Cloud File ID/临时 URL 生命周期与缓存策略。

## 初步判断

- 三张图片同时缺失而 WXML/WXSS 正常，优先排查 WebP 真机解码/打包与开发者工具 `ignoreDevUnusedFiles` 行为。
- 启动关键资源不应只依赖云端网络；优先考虑本地 PNG 兼容资源或本地首屏 + 云端非关键资源。
