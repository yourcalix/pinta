# “拼吧”最小 MVP CCG 审查记录

## 后端与安全

- GPT 5.3 Codex Spark 前两轮发现幂等恢复、并发状态转换和 DTO 暴露风险，主会话已逐项修复。
- 主会话对照 CloudBase 官方文档额外发现事务内不支持 `where()`，已改成确定性文档 ID 与事务内 `doc()` 读写，并增加回归测试。
- 第四轮审查提出旧随机 ID 兼容和客户端身份作用域问题：前者不适用于全新空库 MVP，已写入部署边界；后者已通过不可逆 `sessionScope`、TTL 清理和容量上限修复。
- 第五轮聚焦复核结果：Critical 无，Warning 无；真实 AppID、云环境和并发压力列为部署验证。

## 前端与交互

- 网页版 Gemini 3.6 首轮分析推动取消二次确认、统一卡片、两步表单、离散地点、固定拼车费用和延迟披露等方案落地。
- MVP 实现后复审给出“有条件可交付”。其中“输入没有绑定”为简写摘录造成的误报，真实源码和微信开发者工具自动化均证明输入、备注和勾选事件正常。
- 有效意见已落实：完整读屏标签、进度百分比预计算与边界保护、键盘避让、弹性换行、非招募置灰提示，以及历史申请重新申请状态。
- 网页版 Gemini 3.6 最终修复复核：Critical 无，Warning 无，结论“可交付”；真机大字号、iOS 键盘、低端安卓横向手势和极弱网列入上线前实机矩阵。

## 当前验证

- `npm run verify`：23 项测试全部通过。
- 微信开发者工具游客模式：发现页、详情、申请管理、批准自动成团、成员安全解锁、发布分包和输入绑定均已验证。
- 已知 `touristappid` 微信账号能力告警不影响 Mock 业务；真实云端能力仍需正式 AppID 验证。

## 最终结论

- 后端/安全：GPT 5.3 Codex Spark 终审无 Critical、无 Warning。
- 前端/交互：网页版 Gemini 3.6 终审无 Critical、无 Warning。
- 主会话综合结论：代码级最小 MVP 可交付；正式审核上线仍以真实 AppID、CloudBase、内容安全权限和真机矩阵通过为前置条件。
