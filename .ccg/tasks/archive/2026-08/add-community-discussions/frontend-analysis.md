# 网页版 Gemini 3.7 Flash 前端分析摘要

## 结论

- 推荐 Tab 顺序为 `发现 / 社区 / 发布 / 我的`，浏览入口在左、发布拼车保持核心操作位、个人页在右。
- 社区首页不使用大 Hero；采用紧凑标题、说明和右侧 `+ 发起讨论` Pill。
- 不使用 FAB，避免遮挡原生 TabBar、Safe Area 和帖子正文。
- 帖子卡片显示受控头像、昵称、时间、3 行正文预览、回复数和更多操作。
- 详情页采用固定底部回复输入条，Textarea/Input 需适配键盘与 Safe Area。
- 删除/举报放入原生 ActionSheet，避免卡片表面操作过重。
- 社区 Tab 图标使用绿色/灰色同几何母版的 3D 体素对话气泡。

## 主会话综合调整

- 不采纳“正文前 20 字单独加粗”：原生多节点文本与 3 行 line-clamp 组合会破坏稳定省略和读屏；改为整个正文预览使用统一中等字重。
- `cursor-spacing` 继续沿用项目统一的 120rpx，而不是报告中的 12。
- WXML 无障碍角色使用项目既有标准 `role`，不新增非标准 `aria-role`。
