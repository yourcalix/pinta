# 社区讨论功能初始需求

## 用户目标

在底部导航新增“社区”Tab，供用户浏览和发布讨论帖子。

## 主会话暂定 MVP 边界

- 底部导航扩展为四项，社区为独立主包 Tab 页面。
- 社区支持公开免登录浏览；发帖和回复按动作触发登录并要求资料完整。
- 仅支持文字帖子与文字回复，不开放 UGC 图片、附件、外链或群二维码。
- 社区首页提供分页信息流、加载/空/错误/续页状态和显式“发起讨论”入口。
- 帖子详情展示正文与回复列表；作者可删除自己的帖子或回复，普通用户可使用既有举报能力。
- 服务端是帖子、回复、计数、权限与内容状态的唯一事实来源。
- 发布与回复均经过长度校验、内容安全校验、幂等与频率限制；公开 DTO 不泄露 openid、手机号或内部审核字段。
- 视觉继续使用 `#F5F7F6`、`#16A36A`、白色圆角卡片与现有体素头像/拼图语言。

## 待外部分析确认

- 四个 Tab 的最终顺序与“发布”视觉权重。
- 社区首页是否需要分类 Chip；若有，限定为少量稳定枚举。
- MVP 是否包含回复、删除、举报以及详情分享。
- CloudBase 集合、索引、分页游标、内容安全与并发计数策略。

## 已确认产品方案

- Tab 顺序：`发现 / 社区 / 发布 / 我的`。
- 社区首页使用紧凑标题区与内嵌 `+ 发起讨论` 按钮，不使用大 Hero 或悬浮 FAB。
- 社区不设置分类 Chip，统一按最新发布排序。
- 帖子不设置独立标题，正文列表预览最多 3 行。
- 点击发起讨论时先完成登录与资料完整性校验。
- 详情页采用一层文字回复；输入栏固定在底部并适配键盘与 Safe Area。
- 本人内容通过原生 ActionSheet 删除，他人内容通过原因 ActionSheet 举报。
- 新增社区 Tab 激活/未激活体素对话气泡图标。
