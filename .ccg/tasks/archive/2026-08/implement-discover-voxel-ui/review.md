# 实现前 Web Gemini 3.7 Flash 审查综合

## 必须修改

- Hero 使用真实文字与右下角透明体素校园图分层组合。
- 页面层级固定为 Hero、视角切换、搜索、校区分类、列表。
- 行程卡片改为上方全宽信息、下方独立体素视觉带，避免长路线与素材争夺横向空间。
- 搜索改为内嵌搜索图标，移除外置绿色按钮。
- 所有装饰图片从无障碍树隐藏，卡片继续使用综合读屏标签。

## 建议修改

- 取消卡片内独立“查看行程”按钮，整张卡片作为唯一详情入口。
- 原生 TabBar 直接配置 iconPath / selectedIconPath，不添加自定义 CSS。

## 暂不采纳

- 无。用户已明确优先保留首版图案，本轮审查方案与该决策一致。

## 实施结果

- Hero 使用品牌拼图、真实文字和透明校园场景分层组合。
- 页面顺序调整为 Hero、视角切换、内嵌搜索、校区分类和列表。
- 行程卡片使用全宽路线信息、时间窗、人数、双状态及体素视觉底带。
- 体素视觉底带同时保留头像、起点、虚线、车辆与终点，全部从无障碍树隐藏。
- 原生 TabBar 已配置三组激活/未激活图标。
- 自动化测试 175/175 通过，项目静态检查通过。

## 实现后 Web Gemini 3.7 Flash 复审

- 结论为【可交付】，无 Critical。
- 接受 W-1：空状态按钮改用 `#11784F`、`font-weight: 600` 与 `#E8F5EE` 背景。
- W-2 不采用字体节点 `translateZ(0)` 补丁；将 Unicode 搜索符号替换为纯 WXSS 几何放大镜，从源头消除跨 Android 字体渲染差异。
