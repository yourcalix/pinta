# 社区页体素品牌视觉重构

## 目标

- 保留现有社区浏览、发起讨论、空状态、帖子列表与四栏 TabBar 功能。
- 将当前偏通用的白卡骨架升级为与“发现 / 发布 / 我的”一致的浅灰绿、白卡、翡翠绿与 3D 体素品牌视觉。
- 优先提升首屏品牌识别、发帖入口层级和空状态完成度，不牺牲帖子浏览密度。

## 约束

- 使用真实 WXML/WXSS 渲染文字、按钮和列表，不把页面生成成整张位图。
- 优先复用现有透明 PNG-32 素材与男女头像。
- 保持四栏顺序“发现 / 社区 / 发布 / 我的”。
- 适配 320px、大字号、顶部胶囊、底部 Safe Area 和读屏。

## Gemini 结论综合

- 必须修改：Header 引入体素气泡；空状态替换普通 CSS 加号；发帖按钮降为浅绿；增加轻量背景水印。
- 建议修改：保留“最新讨论 / 数量”标题行，加入小绿点；帖子卡加入居中悬浮短绿线。
- 暂不采纳：Header 再次增加状态栏 padding。页面根节点已经通过 `contentTopInset` 按胶囊底边动态避让，重复添加会制造双重顶距。
