# 基本资料页视觉重构

## 目标

- 以用户提供的 UI 稿为视觉基准，重构 `subpackages/profile/edit`。
- 延续白色大圆角卡片、翡翠绿、体素校园/车辆/头像资产。
- 强化角色选择、昵称、性别、兴趣与成年确认的表单层级。

## 已确认约束

- 用户可见界面不得重新出现“澳门/澳門”。
- 内部 `PILOT_CITY` 继续静默提交，不恢复城市输入框。
- 性别继续只映射受控乘客头像 A/B，不公开原始性别字段。
- 页面是分包资料页，不复制原生 TabBar；沿用原生导航栏与返回行为。
- 只复用仓库现有 PNG，不伪造设计稿中不存在的独立图标资产。
- 保留现有登录、资料加载、校验、角色选择与保存逻辑。
