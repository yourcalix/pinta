# 本人联系电话标题图标提示词需求

- 目标：为发布拼车单页长表单“本人联系电话”标题前生成独立体素电话图标。
- 语义：明确表达本人联系电话，不使用手机屏幕、GPS、聊天气泡或隐私锁等复合语义。
- 风格：与现有绿色体素定位图标、拼图、车辆和校园建筑统一。
- 颜色：品牌绿 `#16A36A` 为主体，允许少量深绿阴影和白色端面高光。
- 构图：单个经典电话听筒，等距 3/4 视角，强轮廓、低细节，适合 58rpx 小尺寸显示。
- 输出：1:1 方形画布、真实 Alpha 透明背景、PNG-32、无文字、无 UI、无底板、无外发光。
- 后续规范：生成原图经裁切后统一压缩为 144×144，保留 2px 透明安全边距。
