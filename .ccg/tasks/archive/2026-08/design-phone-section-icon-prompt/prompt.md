# Image 2 提示词

请生成一个用于微信小程序表单标题前的独立 3D 体素图标：**经典电话听筒（telephone handset）**。

图标由尺寸统一、边角圆润的小型立方体积木拼合而成，整体轮廓简洁清晰，呈自然弯曲的电话听筒形状；听筒从左下向右上轻微倾斜，采用等距 3/4 俯视视角。主体颜色为品牌翡翠绿 `#16A36A`，亮面使用少量清透浅绿高光，侧面与底面使用克制的深绿色阴影；听筒两端各保留一小块白色或极浅灰绿色内侧端面，用于强化听筒语义。材质为温润、精致、略带柔和反射的高级塑料积木，不要金属感，不要霓虹光，不要过度镜面反射。

保持强轮廓和低细节密度，使图标缩小至约 29×29px（小程序 58rpx）时仍能一眼识别为“联系电话”。图标居中，视觉重心稳定，底部仅保留非常轻微、自然、半透明的接触阴影。四周保留约 8% 安全留白，图案不得触碰画布边缘。

输出要求：1:1 正方形画布，建议 1024×1024；单个独立图标；真实 Alpha 透明背景；PNG-32；边缘干净、抗锯齿自然；无任何文字、数字、电话号码、标签、按钮、卡片、界面、边框或背景底板。
