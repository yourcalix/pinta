# 发布讨论页参考式重构

以用户提供的发布讨论截图为结构与卡片视觉母版，重构 `subpackages/community/compose/index`。按用户“保持背景色不变”的明确要求及项目既有设计契约，页面继续使用原深蓝拼图纸纹背景；全局自定义 TabBar 配置和其他页面不得修改，该页面继续作为无 TabBar 的导航子页面。页面采用自定义取消导航、真实账号昵称、500 字纯文字编辑、可插入到正文的真实话题文本、社区守则入口、提交防重、失败保留草稿与提交成功跳详情。

不得新增帖子图片、地理位置、可见性选择、认证身份或后端不存在的结构化话题字段。话题胶囊只能把可见标签写入正文，最终仍沿用现有 `{ content }` API 契约。需要的 3D 装饰素材由用户通过 Image2 生成并以透明 PNG 接入。

Gemini 方案审查 Verdict 为 `APPROVE_PLAN`。实施时需保证话题排重与 500 字上限、320px 下胶囊换行、文档流底部按钮、真实昵称只读加载、输入失败保留草稿。社区守则继续使用微信原生 `wx.showModal`，不搭建自定义遮罩层，避免原生 textarea 层级冲突。
