# 修改后业务方案可行性评估

> 日期：2026-09-01。本评估是产品与技术合规分析，不构成正式法律意见。

## 一、执行结论

修改后的方案并没有整体退出交通服务监管：

- **学生先成团，再由学生在平台外自行选择合法交通工具：Conditional Go。** 前提是平台不建设司机库、不推荐司机、不帮助非持牌司机联系学生、不记录承接关系，并对有偿接载招揽内容进行审核阻断。
- **认证司机在平台内查看已成团需求并自主选单：No-Go（取得相应许可或主管机关书面确认前）。** 该结构仍是“乘客需求池 + 司机供给池 + 平台撮合”，而且“学生先发需求、司机后选单”比传统顺风车更接近根据乘客需求提供预约运输。
- **私信、交换联系方式、线下议价、平台不代收款或不抽佣，均不足以切断平台撮合属性。** 监管会看平台是否聚合出行需求、认证运力、定向展示需求并促成运输关系。

## 二、为什么不属于典型顺风车

内地当前官方定义中，私人小客车合乘的核心是：司机本来就有出行计划，由司机事先发布自己的路线，同路乘客选择乘坐，免费或仅分摊能源和路桥成本。杭州官方进一步明确，“驾驶员先发布，而非根据乘车方需求驾车”是合乘与网约车的本质区别。

本方案恰好相反：

| 维度 | 典型私人合乘 | 修改后方案 |
| --- | --- | --- |
| 谁先发布 | 司机发布既有行程 | 学生发布乘车需求 |
| 路线来源 | 司机原本就要走 | 学生成团需求决定 |
| 司机行为 | 分享空座 | 浏览需求后挑选服务对象 |
| 平台角色 | 展示同路信息 | 聚合需求、认证司机、促成联系 |
| 监管观感 | 同路互助 | 预约运输/叫车/中介撮合 |

因此，把按钮从“接单”改成“选择同行”或把沟通移入私信，只改变界面文案，不改变业务事实。

## 三、两条路径风险矩阵

### 路径 A：学生成团后自行在平台外找交通工具

**判断：Conditional Go，中高风险但可继续降级。**

可以保留：

- 学生认证；
- 学生发布同行需求；
- 其他学生加入和退出；
- 成团后的学生小组聊天；
- 集合时间、集合地点、目的区域；
- 过期、取消、完成和举报。

必须限制：

- 平台不提供司机列表、司机搜索、车辆列表或司机推荐；
- 不向任何司机推送或展示学生需求；
- 不提供司机联系方式入口；
- 不出现报价、车费、司机接送、包车、抢单、接单、司机入驻等字段；
- 私信内容审核应阻断“白牌车”“有偿接送”“司机报价”等招揽；
- 成团页只提示“请自行选择合法公共交通或持牌运输服务”，不能提示去找私人司机。

仍需注意：如果平台明知学生长期利用该功能寻找无牌有偿司机，却继续提供流程引导或放任招揽，仍可能产生协助或放任风险。

### 路径 B：认证司机看成团单并选单

**判断：No-Go，除非完成许可化改造。**

高风险特征：

- 平台建立司机和车辆准入；
- 仅向司机展示成团需求；
- 司机选择具体学生订单；
- 平台记录司机与订单绑定；
- 解锁双方私信或联系方式；
- 后续可能存在报价、评价、投诉、取消和履约状态。

以上结构已经非常接近手机叫车或运输撮合平台。澳门治安警公开口径明确关注手机应用是否召唤并提供载客服务，并明确合法应用叫车应由持牌的士和持证司机提供。澳门第3/2019号法律还覆盖以无有效执照车辆直接或间接获得报酬或其他利益提供有偿客运的行为。

## 四、平台认证会增加什么责任

| 功能 | 增加的责任或风险 |
| --- | --- |
| 审核驾驶证 | 用户会合理理解为平台认可其可提供司机服务 |
| 审核车辆 | 平台已知并管理运力，不再是纯学生信息板 |
| “认证司机”标识 | 形成安全和资格背书；普通驾驶证不等于合法客运资格 |
| 司机订单池 | 定向匹配运输供需，叫车平台特征强 |
| 选单/承接记录 | 形成平台促成运输关系的直接证据 |
| 交换联系方式 | 撮合链路完成，而不是与平台无关 |
| 司机评价、投诉 | 进一步体现平台管理运输服务质量 |

特别需要区分：**验证“有驾驶证”不等于验证“有权提供有偿客运”。** 如果保留司机端，认证对象必须是澳门有效的士/客运营运资格、车辆执照、司机证和对应保险，而不只是普通驾驶证、行驶证。

## 五、推荐产品路线

### 推荐路线 1：学生同行协调平台

状态机：

```text
草稿 → 发布同行需求 → 学生加入 → 同行小组成立
     → 小组自行讨论合法交通方式 → 完成 / 取消 / 过期
```

平台不参与司机、车辆、价格或承接关系。

推荐措辞：

- 同行需求；
- 结伴出行；
- 同学小组；
- 集合时间；
- 集合地点；
- 自行选择合法交通工具。

避免措辞：

- 拼车司机、认证司机、司机任务；
- 接单、抢单、派单、承接；
- 叫车、约车、接送、包车；
- 车费、报价、优先接单。

### 推荐路线 2：合法持牌交通合作

如果必须保留司机市场，则只能向持澳门有效牌照的士、持牌客运企业或得到主管部门确认的合法主体开放，并完成：

1. 澳门交通法律意见；
2. 澳门交通事务局/治安警相关书面确认；
3. 合法营运企业合作协议；
4. 每辆车和每名司机的客运营运资格核验；
5. 乘客、第三者、平台责任保险；
6. 微信交通服务类目书面预审；
7. 事故、投诉、取消、失联、紧急联系与执法协查制度；
8. 收费、消费者权益、税务和跨境数据方案。

在这一路线下，“司机选单”仍可作为产品功能，但它不再是普通校园网络服务，而是受监管的交通合作平台能力。

## 六、最终建议

1. 第一版保留学生侧发布、加入、成团和学生群聊。
2. 暂停上线司机认证、司机订单池、选单和司机联系方式解锁。
3. 成团后引导成员自行选择合法公共交通/持牌运输服务，而不是“自行找司机”。
4. 对群聊中的非法接载招揽、报价和联系方式导流建立机审、举报和封禁规则。
5. 如果商业目标必须包括司机承接，先走持牌交通合作和书面预审路线，再实施代码改造。
