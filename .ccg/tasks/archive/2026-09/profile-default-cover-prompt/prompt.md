# 我的页面默认背景图 Image 2 提示词

用途：微信小程序“我的”页面顶部沉浸式个人主页默认背景。

规格：竖向 1200×1350px；最终导出 WebP；建议控制在 120KB 内。

## 提示词

为一款名为“拼吧”的年轻人结伴活动微信小程序，生成一张“我的”页面顶部默认个人主页背景图。画面是一处安静、清爽、具有轻社交氛围的澳门海边校园步道：远处朦胧的海面、低矮城市轮廓、温柔晨雾与少量绿植，蓝绿色清晨自然光，轻微胶片颗粒和柔焦摄影质感，真实但不过度写实，克制、温暖、年轻，不出现可识别人物或人脸。整体以深海蓝、雾霾蓝、灰青和少量柔和翡翠绿为主，与 #075AA7 深蓝和 #16A36A 翡翠绿品牌色协调。构图必须为移动端 UI 叠字预留空间：顶部 22% 保持低细节、低对比，不放主体；右上区域保持干净，供“编辑主页”胶囊按钮和微信系统胶囊显示；左侧中部 35%—62% 保持柔和暗部和低细节，供圆形头像、昵称和成年标签叠加；主要风景视觉重心放在画面中间偏右，但不得形成抢眼焦点；底部 28% 自然渐变为较深的墨蓝灰，保持均匀安静，确保白色统计数字和文字清晰可读，并可与下方白色圆角内容面板自然衔接。完整铺满画布，无边框、无留白、无文字、无数字、无 Logo、无水印、无 UI 元素、无拼图图标、无高饱和霓虹色、无复杂建筑细节、无强烈阳光光斑。输出为高质量移动端背景图，1200×1350px。
