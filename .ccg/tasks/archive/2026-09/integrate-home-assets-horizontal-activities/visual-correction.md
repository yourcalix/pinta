# 截图比例修正记录

## 问题证据

- 用户提供的当前效果图显示，首版 Hero 仅 `360rpx`，无法形成参考图中占据页面主要纵向面积的生活方式主视觉。
- 快捷卡内插画槽仅 `80rpx`，透明 PNG 的实际主体受 Alpha 留白影响后显得更小。
- 三列活动卡外框已接近参考图，但卡内封面与发起人信息仍像缩略图。

## 修正结果

- 标准屏 Hero 调整为 `560rpx`，主标题 `52rpx`，柔光空槽 `390rpx`；窄屏分别为 `500rpx / 46rpx / 320rpx`。
- 快捷卡调整为 `220rpx` 高、`-98rpx` 叠放、`124rpx` 插图槽；窄屏为 `200rpx / -86rpx / 110rpx`。
- 标准屏活动网格改为 `220 × 3 + 21 × 2 = 702rpx`，卡高 `320rpx`，封面 `132rpx`，插画 `114rpx`。
- 320px 继续保持 `192 × 3 + 12 × 2 = 600rpx`，卡高提升到 `286rpx`，封面 `116rpx`。
- 数据分页、点击、筛选、读屏聚合和 Hero 空图策略均未改变。

## 开发者工具复核

- 独立 iPhone 12/13 Pro 模拟器中，Hero、快捷卡和活动区形成与参考图一致的“大主视觉 → 三卡叠放 → 三列动态”节奏。
- 三列活动没有横向溢出；快捷卡文字与放大后的透明 PNG 未发生重叠；Hero 空槽无破图标识。
