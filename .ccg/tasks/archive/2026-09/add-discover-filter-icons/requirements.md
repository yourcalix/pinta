# 需求

在发现页类型筛选的“全部 / 拼同行 / 拼运动 / 拼饭桌”文字前加入用户提供的对应图标，保持现有筛选行为、横向滚动、选中态颜色和无障碍语义不变。

## 素材映射

- `全部.png` → 全部
- `同行.png` → 拼同行
- `运动.png` → 拼运动
- `饭桌.png` → 拼饭桌

源素材位于 `/Users/cx/Desktop/pinba/模块图标`，均为 1254×1254、无透明通道的黑白 PNG，单张约 680–890KB。

## 实施边界

- 原始素材不得直接进入主包；需缩放并压缩为稳定英文文件名的小尺寸资源。
- 图标作为装饰退出无障碍树，按钮本身继续提供完整标签与选中态。
- 图标不得挤压文字、破坏 44px 触控热区或导致 320px 窄屏异常。
- 保持四个筛选项可横向扩展，不修改筛选逻辑和 API。
- 增加资源尺寸、路径白名单和模板呈现测试。
