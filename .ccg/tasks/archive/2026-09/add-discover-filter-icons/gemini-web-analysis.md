# 网页版 Gemini 3.7 Flash 分析

## 采纳结论

- 图标在标准屏显示为 36rpx 正圆徽标，文字间距 10rpx；320px 下缩为 32rpx 与 8rpx 间距。
- 原图缩放为 72×72 小图，不直接打包 1254×1254 源文件。
- 图标保留白底并由圆形容器裁切，未选中使用奶油描边，选中态使用半透明浅色描边与轻阴影。
- 图标容器和图片均退出无障碍树并禁用指针事件；按钮保留完整 tab 语义。
- 类型切换逻辑保持不变，仅为 `typeOptions` 增加静态白名单路径。

## 主会话调整

- 保留发现页现有横向溢出宽度与阴影布局，不采用会改变右侧露出效果的 `width: 100%` 建议。
- 资产使用压缩 PNG，避免为四张极小黑白图引入格式解码差异；测试约束尺寸与总字节数。
