# 需求

- 以当前“我的”页面为视觉基准，重构“发现”页面，使两个一级 Tab 呈现同一套沉浸式、现代、克制的界面语言。
- 保留发现页现有搜索、四类筛选、活动计数、活动列表、分页/空态/错误态和整卡导航行为。
- 保留现有品牌深蓝背景、翡翠绿强调色、活动类型插画及自定义 TabBar。
- 重点统一顶部安全区、背景层次、圆角白色内容面板、字号层级、留白密度、标签与卡片质感。
- 不修改活动数据契约、接口、登录策略或活动状态机。
- 兼容 320px 窄屏、Safe Area、微信胶囊和真机 PNG/JPEG 资源规范。

# 综合后的设计决策

- 必须修改：采用“深蓝沉浸头部 + 100vw 连续白色圆角内容面板”，将搜索、筛选、列表及全部状态收进白色面板。
- 必须修改：仅重塑 `activity-card` 的 `discover` 变体为规整白卡、轻边框和浅阴影，其他变体保持不变。
- 建议修改：筛选项使用原色图标、灰色未选态和翡翠绿浅色选中态；列表底部由白色面板统一提供 TabBar 与 Safe Area 避让。
- 暂不采纳：不把搜索改为实时请求；继续保留 `keyword` 与 `appliedKeyword` 分离以及点击/键盘确认后搜索的现有行为。

# 新增范围：发现页运营 Banner

- 在发现页上方加入可自动循环展示的站内运营 Banner，不接入微信商业广告组件。
- Banner 使用受控数据与受控本地图片，不直接复用参考截图中的第三方品牌、商品或价格素材。
- 需要与“深蓝沉浸头部 + 白色内容面板”骨架兼容，并明确放置在品牌头部与搜索筛选之间的最佳位置。
- 默认采用自动轮播、手势切换、页码指示；页面隐藏后不得保留自建定时器。
- 点击去向必须使用本地路由白名单；未配置去向时整张 Banner 只展示、不制造无效点击。
- 需覆盖单张、多张、图片加载失败、320px 窄屏、Safe Area 和 TabBar 避让。

# 新增范围：成团记忆与新版整页视觉

- 在 Banner、搜索与活动流下方加入“成团记忆”板块，参考新截图的主题标题、彩色大面板与不对称内容拼贴结构。
- 新参考图成为发现页新的主要视觉依据：整体转向更明亮的白色基底、饱和但受控的蓝色运营面板和内容型卡片，同时保留拼吧深蓝与翡翠绿品牌识别。
- 不复制参考图中的皇家加勒比 Logo、游轮、促销金额、用户照片或第三方文案。
- 当前活动契约没有回忆照片字段，首版不得伪造真实用户照片；优先使用真实已成团活动的标题、日期、类型插画、成员头像和人数形成记忆拼贴。
- 成团记忆只展示服务端明确公开且状态为 `FORMED` 的活动；不得从标题、人数或日期在前端自行推断成团状态。
- 点击记忆卡进入对应公开活动详情；无真实成团数据或独立请求失败时静默隐藏整块内容，不以 Mock 图片冒充用户回忆。
- 若要开放活动回忆照片上传，必须作为后续独立的图片审核、隐私、存储和删除治理任务处理，不纳入本轮。
- 成团记忆首屏固定展示最多 3 条，接口最多返回 6 条；第 4–6 条通过本页“看看搭子们都拼了什么”展开，暂不创建需求不完整的二级历史页。
- 运营 Banner 首版使用项目内已有 PNG 插画和 CSS 渐变组成三张受控站内卡片，不新增 WebP 或第三方商业素材。
