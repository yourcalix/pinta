# Web Gemini 3.7 Flash 前端分析综合

## 采纳

- 使用微信官方 `custom-tab-bar`，五栏固定为发现 / 社区 / 发布 / 消息 / 我的。
- 每个 Tab 页在 `onShow` 主动同步 `selected`，组件内部点击只负责 `wx.switchTab`。
- 五列严格 `20%` 等分；中央拼图只纵向越界，点击热区不得横向侵入相邻列。
- 中央拼图视觉尺寸 `112rpx × 112rpx`，上浮 `32rpx`；默认与激活素材同画布同几何。
- 所有 Tab 页面底部统一避让 `120rpx + safe-area`。
- 聊天详情放独立分包页面，不渲染 TabBar，软键盘使用原生 adjust-position。
- 消息页将系统通知入口与一对一会话物理分组，不混为同一会话类型。
- 未读数 0 隐藏、1–99 显示数字、超过 99 显示 99+。

## 调整后采纳

- Badge 不在进入消息 Tab 时清零；只有具体会话成功标记已读后才扣减。这与服务端 readState 事实一致，避免视觉先于数据。
- 现有发现、社区、发布、我的图标优先复用；只新增消息默认/激活图标及发布拼图默认/激活母版，待视觉核验后再决定是否重绘其余四套。
- 首期成员私信只从受后端校验的同活动成员关系入口开放；社区作者私信后置。

## 暂不采纳

- 不锁死 TabBar 字号绕过系统可访问性设置；优先通过单行、合理宽度与语义标签保证大字号可用。
- 不使用三维塑料拼图；保持已确定的油画棒手绘纸片风格。
