# 发现页设计任务书（Gemini 审查稿）

## 页面职责

发现页负责公开活动浏览、搜索、类型筛选和进入详情；不承担发布入口选择，不复制发布页的三张大画廊卡。

## 推荐层级

1. 固定深蓝粗纹纸背景与自定义导航安全区。
2. 紧凑品牌标题：“拼吧 · 发现” / “今天和同学拼什么？”；不使用占据首屏的大 Hero。
3. 奶油白手绘搜索框，搜索活动、地点或发起人。
4. 横向可滑类型 Chip：全部 / 拼同行 / 拼运动 / 拼饭桌；未来可追加新类型。
5. 列表标题：“正在组队”或“筛选结果”，附活动数量与清除筛选。
6. 高密度奶油白活动卡片流：类型、状态、标题、场景摘要、时间、地点/人数、进度、发起人和详情提示。
7. loading / empty / error / load-more / end 状态。

## 视觉规则

- 背景复用发布页的深蓝纸纹，但发现页首屏信息密度更高。
- 卡片使用奶油白 `#FFF7E8`，深墨蓝正文；保留轻微不规则手绘边线与低对比阴影。
- 类型色只用于标签、短边线和进度：同行青绿、运动紫、饭桌橙。
- 搜索、筛选和活动卡全部使用原生 WXML/WXSS；不把文字烘焙进图片。
- 不为每条列表卡增加大插画，避免重复视觉和长列表性能问题；最多使用少量CSS线条/字符图标。
- 继续使用 Native TabBar，不绘制自定义底栏。

## 状态与可访问性

- 320px 下筛选改横向滚动，卡片元信息允许换行。
- 大字号下所有卡片使用 `min-height` 而非固定高度。
- 活动卡读屏标签包含类型、标题、状态、时间、地点和名额。
- 深蓝背景不直接承载中灰小字；所有辅助正文进入奶油白容器或使用高对比奶油白。
- 启动动画、分页、请求竞态、过期刷新与业务接口保持不变。

## 资产结论（本轮）

- 背景直接复用 `publish-paper-texture.webp`。
- 首版不要求生成新人物或场景插画；先用纯 WXML/WXSS 完成布局并验证信息密度。
- 若审查确认顶部确需装饰，再单独生成一张小型透明手绘贴纸，不生成整页切图。
