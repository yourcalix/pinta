# GPT 5.5 诊断摘要

## 根因概率排序

1. 高概率：微信开发者工具或小程序运行时存在 `process` polyfill，`runtime.js` 因 `process.versions.node` 错误跳过 `local.js`，回退到 `useMock: true`。
2. 中高概率：`local.js` 加载异常被静默吞掉，同样回退为 Mock。
3. 高确定性产品缺陷：Mock 未命中和真实高德零结果共用同一空态，环境错误被伪装为“没有找到地点”。
4. 次要可能：高德返回 tips，但所有候选因缺坐标或澳门边界规则被静默过滤。

## 已有证据

- 当前本地 Key 直接请求高德 Input Tips API 成功，`澳门大学`、`塔石体育馆`、`大三巴` 均返回 `status=1` 与带坐标候选。
- 页面只有 `searchPoi()` 成功返回空数组才显示“没有找到地点”；域名、网络或鉴权失败应进入错误态。
- 默认配置为 `useMock: true`，Mock 仅包含四个地点，绝大多数真实关键词都会返回空数组。

## 建议

- 小程序运行时以 `wx` 存在作为允许加载本地配置的首要信号，不得被 `process` polyfill 否决。
- 保持 Node 测试环境不读取真实 `local.js`。
- Mock 未命中、配置缺失、响应结构异常、候选全被过滤、真正零结果必须区分。
- 真实高德错误不得泄露 Key 或原始服务错误。
