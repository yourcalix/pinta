# 需求说明

## 用户目标

1. 将原“发现”Tab 的用户可见名称改为“首页”。
2. 将原“社区”Tab 的用户可见名称改为“发现”。
3. 参考用户提供的 Concept A 页面，重新设计五栏自定义 TabBar。
4. 丢弃原发现页与社区页的既有版式，以参考图的温暖米白、3D 生活方式首页语言重新排版。

## 业务边界

- 保留 `pages/discover/index` 与 `pages/community/index` 的物理路径，避免扩大到通知、分享、详情返回等路由迁移。
- 首页继续消费真实活动数据、筛选与游标分页能力；发现页继续消费真实社区帖子 DTO 与发帖/详情能力。
- 不伪造天气、通知红点、用户照片、邻里动态、浏览量或不存在的栏目。
- 参考图的三张快捷卡映射到真实入口：活动浏览、发现讨论、发起拼单；具体文案在设计分析后定稿。
- 中央发布按钮继续复用现有发布 Tab，不改业务门禁和发布流程。
- 头像只使用已经允许公开或本地受控的资源；不得扩大隐私字段。

## 验收目标

- Tab 顺序和用户可见文案为：首页 / 发现 / 发布 / 消息 / 我的。
- 首页具备问候区、生活方式 Hero、三张快捷卡、真实活动内容区；首屏主路径明确。
- 发现页成为真实讨论发现流，保持加载、空态、错误态、续页与发布入口。
- TabBar 与参考图一致采用白色悬浮圆角底板、黑灰图标、中央黑色圆形加号、选中态黄色微标。
- 375px 与 320px 下无溢出；交互热区不小于 88rpx；兼容底部 Safe Area。
- 自动化测试、静态检查和微信开发者工具视觉检查通过。
