# 需求

将发现页“热门拼吧”模块改造成与“成团记忆”同源的画报背景风格，同时保持活动列表的真实数据、每页五条分页、整卡跳转和现有加载/空态/错误态。

## 设计目标

- 两个章节继续使用相同的居中英文水印 + 中文主标题基线。
- “热门拼吧”区域引入与“成团记忆”呼应的蓝色画报背景、柔和光晕、背景图层和白色/半透明内容容器。
- 活动卡仍维持参考图批准的左侧大图、右侧文字信息结构，不改业务字段与分页逻辑。
- 让五张活动卡在专题背景中有明确层级，避免直接复制静态预告的 347:430 三格结构。
- 保证 375px、320px、大字体、真机图片格式与底部 TabBar 安全区。

## 边界

- 不新增远程图片、虚构活动数据、促销数字或营销指标。
- 不改服务、API、游标分页、筛选与搜索行为。
- 不影响“成团记忆”静态预告定位。
- 背景优先复用现有本地 Baseline JPEG；如确需新资源，必须是受控 PNG/JPEG。
