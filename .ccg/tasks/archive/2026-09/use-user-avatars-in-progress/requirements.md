# 需求与假设

## 目标

- 发现页活动卡、活动详情“一起组队”等人数进度区域优先显示实际参与用户的当前头像。
- 不再展示已废弃的 `avatar-passenger-*.png` 像素头像。
- 没有自定义头像时使用当前按性别生成的手绘头像；历史数据无法关联用户时展示空槽，不伪造头像。

## 隐私与安全

- 只输出专用于展示的头像引用，不公开 userId、memberId、上传记录、存储内部路径或其他本人资料。
- 必须评估自定义头像从“仅本人页面”扩大到公开活动进度的隐私告知、云存储访问和内容审核影响。
- 活动退出、头像变更与恢复默认后，进度头像需与成员事实和当前资料保持一致或具备明确的快照策略。

## 非目标

- 不改变社区、私信或群聊头像。
- 不伪造历史成员头像，不恢复废弃像素资源。
