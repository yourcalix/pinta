# 主会话初步分析

- 截图中的活动空态复用了公共组件 `default` 规格：组件自身最小高度 `420rpx`、插画 `260rpx`、按钮 `88rpx`，再叠加首页外壳 `32rpx` 纵向内边距，明显超过固定视口内活动区域可用高度。
- 首页非空列表使用三列活动卡，标准屏高 `275rpx`、320px 高 `240rpx`；本轮不能修改这些既有比例。
- 推荐为公共组件增加受控 `compact` 规格，并仅在首页空态传入。首页空态外壳使用与活动预览区相匹配的固定高度/裁切保护；插画、文字间距和按钮表面缩小，但按钮实际触控高度仍保持至少 `88rpx`。
- 加载骨架与有内容分支不追加新类、不修改现有尺寸，从模板和测试层锁定“只改空态”。
