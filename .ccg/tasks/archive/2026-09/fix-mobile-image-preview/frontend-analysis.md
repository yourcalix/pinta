# 网页版 Gemini 3.7 Flash 前端分析

## 结论

- 确认根因是 `wx.previewImage` 原生组件与页面 `<image>` 的路径解析能力不同。
- 要求包内资源、`cloud://`、HTTPS 和临时文件在预览前统一转成本地可读路径。
- 要求完整异步互斥、Loading 清理、页面卸载保护和失效临时路径降级。
- 方案可实施。

## 已应用

- 新增统一异步路径解析和沙盒文件存在性验证。
- 云文件与 HTTPS 文件分别前置下载。
- 自定义头像失败时回退受控手绘头像，头像氛围背景使用相同规则。
- 页面隐藏或卸载时使旧预览请求失效并清理 Loading。
