## 主要确认项

- 暖米白背景、居中标题、三张 140rpx 大圆角入口卡片、3D 黏土图标和真实未读红点与参考图的核心层级一致。
- 活动通知使用确定性白名单分类，未知类型安全归入系统通知。
- 数据源异常时保留上一次有效未读状态，避免弱网下红点错误清零。
- 私信区域只消费真实会话与纯文本来源摘要，不伪造用户、帖子图片或通知。
- 64×64 索引色 PNG 在约 48 CSS px 的展示尺寸下属于主包预算约束中的合理取舍。
- 320px 窄屏、导航防重、无障碍语义与真实未读消除流程均具备验收防线。
