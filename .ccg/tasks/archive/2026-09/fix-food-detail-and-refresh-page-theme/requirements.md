# 拼饭桌地点查看与全站暖米白背景改造

## 用户目标

1. 修复“拼好饭 / 拼饭桌”详情页集合地点看似可点、实际无法查看的问题。
2. 发布者使用的申请/成员管理页改为与首页一致的暖米白生活方式风格。
3. 普通业务页面彻底移除旧 `#075AA7` 深蓝背景与深蓝纸纹遮罩。

## 已确认边界

- 公开活动 DTO 已返回 `meetingPoint.label/address`，不公开经纬度、POI ID、adcode 或 `meetingGeoPoint`。
- 地点查看仅展示公开名称和地址，不打开地图、不反查坐标、不修改云函数。
- 历史活动缺少 `meetingPoint` 时兼容 `sceneLine/placeLabel`；全部缺失时给出诚实提示。
- 搭子星球的暗夜 Canvas 是独立产品主题，继续保留。
- “我的”真实头像沉浸背景继续保留，普通内容面板保持暖米白。
- 非深蓝的活动类型海报底色、插画与品牌状态色不属于本次移除范围。

## 验收标准

- 点击详情页集合地点行能查看完整公开地点名称和地址。
- 管理页使用暖米白底、白色卡片、黑色文字和首页品牌绿色主动作。
- 普通页面顶部、下拉回弹、加载态与内容区不再露出旧深蓝。
- 320px、系统大字、iOS/Android 下无溢出或不可点击。
- 现有业务状态、接口契约、隐私边界与特殊沉浸主题不变。
