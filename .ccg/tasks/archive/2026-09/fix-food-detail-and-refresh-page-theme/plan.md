# 实施计划

## 1. 先建立回归门禁

- 重写全局背景测试：普通页面禁止 `#075AA7/#075aa7` 和 `shared-paper-bg.jpg`；搭子星球暗夜主题显式豁免。
- 为活动详情增加地点弹层状态机、字段回退和“不调用地图 API”的测试。
- 更新既有发布页、发布表单与个人主页测试，使其符合暖米白托底和沉浸式例外的新规范。

## 2. 全局暖米白基础设施

- 修改 `app.json` 默认窗口为 `#F9F7F2 + black + dark`。
- 修改 `app.wxss` 的 `page/.global-background-host` 为暖米白，并移除旧全屏背景/tint 通用样式。
- 普通页面 JSON 同步改为暖米白占位和黑色状态栏。

## 3. 普通页面移除旧背景节点并反色

- 发布入口、申请管理、成员空间、发布表单、私信、群聊、举报页移除 `shared-paper-bg` 与 tint 节点。
- 修复原来依赖深蓝底的白字、白边框、时间文字、空态图标和导航箭头。
- 保持发布入口单视口、表单键盘避让、聊天气泡关系和危险操作语义不变。

## 4. 管理页首页风格重构

- 使用暖米白页面、白色大圆角摘要卡/申请卡、品牌绿主操作与红色危险区。
- 操作按钮保持 88rpx 真实热区；长昵称、长说明和 320px 使用弹性布局。

## 5. 集合地点安全查看

- 详情页注册现有 `pinba-modal`。
- 地点行改为 88rpx 可访问按钮热区。
- 前端只组装公开 `label/address`，兼容历史 `sceneLine/placeLabel`；不打开地图、不新增后端字段。

## 6. 规范、验证与审查

- 更新前端 Spec，废止旧深蓝/共享纸纹要求，记录暗夜星球与个人主页沉浸背景例外。
- 跑专项测试、全量 `npm run verify`、包体检查与 `git diff --check`。
- 按 CCG 路由生成 Gemini 前端复审 Prompt并等待用户贴回；若无 Critical，归档任务并提交。
