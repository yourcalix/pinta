# Web Gemini 3.7 Flash 前端分析摘要

- 使用 `<button open-type="chooseAvatar">`，整行作为头像选择热区。
- 保留 120rpx 头像、标题与辅助说明，右侧增加箭头；上传中显示局部遮罩和状态文案。
- 上传动作与普通资料草稿严格隔离，成功后只更新头像字段，禁止重新加载整个表单。
- 临时路径只能用于上传中的即时预览，确认成功后才切换为持久化引用。
- 自定义头像加载失败时静默回退性别手绘头像。
- 上传成功明确 Toast“头像已更换”，避免用户误以为还需要点击底部保存资料。
- 已有自定义头像时提供恢复默认入口；本实现采用独立次级按钮，头像整行仍保持直接选择。
- 上传期间禁用重复选择，提供无障碍状态播报，320px 下收紧头像尺寸和文案宽度。

## 综合采纳

- 必须：chooseAvatar、上传锁、局部状态、草稿隔离、破图回退、明确成功/失败反馈。
- 采纳调整：恢复默认采用独立按钮，不使用点击头像后的 ActionSheet，避免破坏“点击头像直接上传”的用户要求。
- 不采纳：年龄确认展示行；该行已按用户此前要求删除。
