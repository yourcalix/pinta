# Gemini 3.7 Flash 前端分析摘要

## 推荐布局

- 发现卡底部左侧用头像槽位组替代单独发起人昵称，右侧保留明确数字进度。
- 2–4 人显示最多 4 个完整真实/空槽；5–7 人显示 3 槽 + `+N`；8–20 人显示 2 槽 + `+N`。
- EMPTY 使用浅奶油灰、虚线圆框和中性圆点，不伪装成用户。
- 标准屏槽位 36rpx、重叠 -10rpx；320px 窄屏 30rpx、重叠 -8rpx。

## 微动效

- 仅真实头像以 opacity + scale 单次阶梯淡入，220ms，每槽延迟 45ms，总时长不超过 350ms。
- 空槽和 `+N` 静态；`prefers-reduced-motion` 下关闭动画。
- 撤销上一版人数文字和箭头动画。

## 风险

- 320px 下长容量文字必须 nowrap，并减少可见槽位数。
- 重叠头像显式设置递减 z-index，避免不同 WebView 覆盖顺序差异。
