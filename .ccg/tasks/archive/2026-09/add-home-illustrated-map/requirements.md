# 首页手绘拼吧地图需求

## 目标

- 将首页第三张“暂定 / 模块占位”快捷卡替换为可点击的“拼吧地图”。
- 点击后进入独立手绘地图页面，使用用户提供的 941×1672 无透明 PNG 作为唯一主视觉来源。
- 首页另外两张快捷卡、Hero、活动卡、骨架屏和固定单视口比例保持不变。

## 产品假设

- 本期地图是活动类型的插画式导航地图，不是 GPS 地图，不申请定位权限。
- 四块木牌分别承载“拼同行 / 拼运动 / 拼饭桌 / 拼享惠”，点击进入全城活动列表并预选对应类型。
- 原画中营火旁的第五块木牌仅作为环境装饰，不叠加文字、点击热区或虚构业务。
- 一期点击木牌直接进入预选类型的全城活动列表，不新增活动数量摘要接口或二次浮泡。
- 页面必须提供清晰返回操作；热点失败时释放防重锁并给出轻提示。

## 视觉与适配

- 原画完整显示、零拉伸、零裁切；允许以同色纸纹背景承接长屏上下留白。
- 地图画布严格按原图比例锁定为 `100vw × 177.68vw`，禁止使用 `aspectFill`。
- 四个木牌热点中心坐标冻结为：拼同行 `42.0% / 8.4%`、拼运动 `83.2% / 28.8%`、拼饭桌 `37.0% / 34.2%`、拼享惠 `84.8% / 79.6%`。
- 页面采用独立分包，原始 3.3MB PNG 需转为受控尺寸的 Baseline JPEG，守住单分包体积预算。
- 320×568、375×667、现代 iPhone 与 20:9 Android 均需保证返回键、木牌文字和热点完整可见。
- 木牌热点为真实按钮，触控区域不小于 88rpx；装饰画面退出无障碍树，页面提供聚合说明。
- 系统大字模式不得使木牌文字越界；必要时收敛字号而不是裁切画面。

## 工程边界

- 新页面建议归属 `subpackages/map/`，避免主包继续增长。
- 首页仅新增地图入口与防重复导航锁；不更改现有首屏数据加载、启动层或欢迎 IP 状态机。
- 活动列表只接受 `companion | sport | food | benefit` 四个白名单查询值，非法值降级为全部。
- 新增专项测试覆盖路由注册、首页比例不变、图片编码尺寸、热点语义、查询白名单和生命周期锁释放。
