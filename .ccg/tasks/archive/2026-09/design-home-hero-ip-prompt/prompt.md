# 首页猫狗 IP Hero 生图提示词

## 主提示词

为微信小程序“拼吧”绘制一张竖版首页 Hero 透明插画，画布比例 1:2，最终尺寸 600×1200px，完整透明背景、PNG、保留平滑 Alpha 边缘。

画面主角必须严格沿用现有品牌 IP：一只奶油白色、棕色垂耳的小狗，戴森林绿色三角巾；一只圆润的黑猫，戴暖橙红色三角巾。两只角色都有大而圆润的黑色亮眼睛、细小高光、粉色腮红、短小圆润的四肢，神态善良、好奇、亲切，比例软萌但不过度幼儿化。角色造型、脸型、眼睛与水彩纸纹要像同一套品牌插画，不得换成写实动物或普通卡通猫狗。

场景主题是“世界很大，先来拼吧”：小狗和黑猫在一段温暖的奶油白石阶/露台上共同拼合三块大号拼图，拼图使用克制的奶油黄、鼠尾草绿、柔和天蓝与淡紫色；黑猫扶着其中一块，小狗开心地把另一块放到一起，传达认识新伙伴、一起出发、共同完成事情的感觉。周围自然散落相机、羽毛球拍、小型旅行地图或帆布背包、野餐篮等生活方式元素，但只作次要装饰，不能抢过角色和拼图。石阶边缘生长低饱和绿色藤蔓、小白雏菊与少量暖黄色花朵，右上侧可有一盏温暖的小壁灯和少量爬藤，形成轻微的生活场景框景。

构图必须严格适配现有首页：主体整体锚定在画布右下区域；画布左上约 55% 宽、前 32% 高必须保持完全透明的大面积负空间，用于页面标题和说明文字；角色头部不得进入左上文字安全区。两只角色及正在拼合的拼图是核心视觉，安排在 x=150–575px、y=350–840px 范围内，脸部与拼图必须位于画布高度 35%–70% 的清晰区域。所有关键角色、脸、手和拼图必须位于画布高度 74% 以上的非渐隐安全区内；画布 74%–100% 高度只放石阶、藤蔓、花草与相机等可被页面渐隐遮罩淡出的次要装饰。主体四周至少保留 20px 透明安全边距，不得切断耳朵、尾巴、四肢、拼图或道具。

视觉风格：温暖的儿童绘本水彩与蜡笔纸纹结合，手绘铅笔轮廓，细腻颗粒纸张质感，柔和不规则上色边缘，低饱和奶油色、森林绿、暖橙、淡黄、天蓝和薰衣草紫；明亮、松弛、治愈、有生活气息。光线像清晨柔和自然光，阴影轻微且透明，不要厚重投影。插画需要在手机小尺寸显示时仍能清楚识别角色轮廓和拼图动作。

画面中不要出现任何文字、字母、数字、Logo、按钮、界面框、标题或水印。不要生成完整背景色块、天空或房间墙面，除角色与场景元素外全部透明。

## 负面提示词

不要人类角色，不要第三只动物，不要写实摄影，不要 3D、黏土、塑料玩具、像素风、矢量扁平风、动漫赛璐璐、迪士尼风、过粗黑描边、高饱和荧光色、复杂城市背景、满版场景、纯白或棋盘格假透明背景、文字、Logo、水印、UI、二维码。不要尖锐牙齿、凶狠表情、细长四肢、比例怪异、额外肢体、重复尾巴、融合的爪子、畸形拼图。不要让主体居中占满画布，不要占用左上文字安全区，不要让角色脸部或拼图落入底部 26% 渐隐区，不要裁切任何关键元素。

## 参考图使用顺序

1. 上传 `activity.png` 与 `search.png`，作为角色造型、眼睛、腮红、水彩纸纹和配色的最高优先级参考。
2. 上传旧版 `hero-community-puzzle.png`，仅参考 1:2 透明画布、右下主体与左上留白构图；不要复刻其中的人类角色。
3. 若工具支持参考权重：猫狗 IP 参考 80%，旧 Hero 构图参考 20%。

## 导出要求

- 文件名：`hero-community-pets.png`
- 画布：600×1200px
- 格式：透明 PNG，非预乘黑底，非 WebP
- 页面内使用 `aspectFit`
- 导出后检查左上透明安全区、角色完整性与底部渐隐兼容性
