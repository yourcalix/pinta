# 修复他人公开主页关注操作失败

## 用户现象

在他人的公开主页点击“关注”后，页面提示“操作失败，请稍后重试”。

## 目标

1. 定位失败发生在短期主页凭据、客户端请求封装、服务端关注校验或 Cloud 数据事务的具体环节。
2. 修复后关注与取消关注均能成功，并保持现有乐观更新、失败回滚、防重锁和隐私边界。
3. 不向客户端暴露稳定 userId、openid 或内部数据库错误。
4. 补充覆盖真实失败根因的自动化测试，并运行全量验证。

## 验收结果

- [x] 权威确认真实根因是目标环境缺少 `profileFollows` 集合。
- [x] 创建集合并部署当前 API 云函数。
- [x] 真机关注成功，粉丝数增加 1。
- [x] 真机取消关注成功，粉丝数恢复且关系不再激活。
- [x] 全量验证通过，无前端隐私契约变化。
