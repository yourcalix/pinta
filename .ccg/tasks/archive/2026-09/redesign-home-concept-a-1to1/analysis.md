# 分析结论

依据用户回传的网页版 Gemini 3.7 Flash 分析，主会话采用以下方案：

- 首页使用 750rpx 基准：28rpx 页面左右边距、88rpx 问候栏、360rpx Hero、三卡向上重叠 68rpx。
- Hero 本轮不渲染图片节点，仅保留无边框、无破图语义的径向柔光插槽，并退出无障碍树。
- 三张快捷卡标准屏高 210rpx，320px 高 190rpx；第一张锚定活动区，第二张只显示即将开放 Toast，第三张不可点击且退出交互树。
- 用户指定文案原样保留，不采纳外部模型提出的替代副标。
- 活动继续使用纵向 46:54 完整画报卡，首页初始批次改为 3 条。
- “查看更多”采用原地游标追加，每次追加 3 条；失败保留已加载内容并恢复按钮，直到无下一游标后隐藏按钮并显示终点文案。不伪造总页数，不一次拉取全量数据。
- 小尺寸搜索、通知、箭头和 TabBar 图标继续使用现有 CSS，以保证 DPR 清晰度；用户生成的透明 PNG 仅用于三张快捷卡，资产到达前采用不产生破图的 CSS 插槽。
