# 实施计划

1. 重构首页 WXML：调整问候、Hero、三卡叠层、附近拼吧章节与活动列表，移除当前搜索筛选工具带的首屏占位；保留真实加载、空态、错误态和活动详情入口。
2. 重构首页 WXSS：按 Concept A 参数建立暖米白底板、360rpx Hero、负边距三卡、克制叠层阴影、320px 断点和 TabBar 安全区。
3. 重构首页活动状态：首批及续批均按 3 条游标请求；“查看更多”原地追加去重，使用序列号与 pending 锁防止旧请求和连点竞态；筛选底层能力暂不删除。
4. 为用户后续生成的三张 PNG 预留稳定资产路径和无破图 CSS 降级；Hero 仅留空槽。
5. 更新首页视觉、交互、分页与导航专项测试，补充 3 条首批、追加、失败保留和末页收口覆盖。
6. 运行定向测试、全量验证与微信开发者工具双尺寸视觉检查。
7. 输出网页版 Gemini 复审提示词；根据回传修复后记录审查、更新前端规范、归档任务并提交。
