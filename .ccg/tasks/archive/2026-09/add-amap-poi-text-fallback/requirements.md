# 需求

部分地点关键词在高德 Input Tips 中能搜索到名称，但候选缺少经纬度，页面因此提示“搜索到了地点，但暂时无法取得有效坐标”。需要在保持坐标真实性与澳门边界校验的前提下，自动使用 POI 文本检索取得可发布的真实坐标。

## 验收标准

- Input Tips 存在有效坐标时直接使用，不发起多余请求。
- Input Tips 有候选但无有效坐标时，自动调用高德 POI 文本检索兜底。
- Input Tips 真正为空时，也允许文本检索弥补提示接口的覆盖差异。
- 兜底结果继续执行澳门边界、名称、坐标与字段白名单校验。
- 两层都没有有效地点时才显示准确的空态或坐标不可用错误。
- 任一层的网络、鉴权、服务异常不得泄露 Key 或原始上游错误。
- 不保存用户实时位置，不扩大搜索范围到澳门之外。
