# Requirements

- 将用户压缩包中已经完成的“拼同行”发布界面迁入当前工程。
- 只改变 `type === 'companion'` 的可见界面及其必要交互适配。
- 保持拼运动、拼饭桌、发布入口和其他页面的可见界面、文案、交互及数据契约不变。
- 不用压缩包中的旧工程文件覆盖当前 Cloud/Mock、拼饭桌、包体预算或现有测试改动。
- 新素材必须归属发布分包、使用 iPhone 微信稳定格式，并保持主包与发布分包预算通过。
- 补齐分支隔离、字段提交、素材路径、键盘与安全区回归测试，并通过真机预览构建。
- 不迁入候选快照中的活动图片上传：它违反当前“仅本人头像可上传”的 MVP 安全规范。
- 不迁入 `requiresApproval` 开关：非拼车活动继续沿用现有统一申请审批流。
- 候选“拼友数”按“不含发起人”的 UI 语义呈现，提交时转换为现有“含发起人总人数”2—20 契约。
- 候选 10 分钟时间段不伪造结束时间：改为单点出发时间并保留现有 `timeFlexibility` 三档真实契约。
- 九项同行偏好如进入界面，必须使用严格枚举并在 Cloud、Mock 与公开 DTO 中保持同构，选填缺省兼容旧客户端。
