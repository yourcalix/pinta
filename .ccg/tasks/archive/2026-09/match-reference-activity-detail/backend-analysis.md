## 已核验与推荐

- 现有 group 页面是成员空间，不是真实群聊；现有 DM 只允许共同成团 ACTIVE 成员创建会话。
- 咨询复用 directConversations/directMessages，新增 OWNER_CONSULT 类型与 dm.consult.create(activityId)，旧会话默认 MEMBER_DM，旧 resolveDirectMessagePeer 不放宽。咨询对象由后端活动 owner 决定，不接受任意用户 ID。
- 群聊独立 activityGroupMessages、activityGroupReadStates 和可选摘要集合；建议 group.message.list/send/read，服务端每次校验活动、账号和当前成员状态。
- 招募中已获批 ACTIVE 成员可群聊；退出成员禁读写；终态 ACTIVE 成员只读；下架禁读写。发送事务内重新校验，避免退出并发穿透。
- 消息稳定 ID 包含活动、发送者与 clientMessageId，payloadHash 校验幂等冲突；复用内容安全检查、审核、独立限流桶；幂等重试不得重复计数。
- 咨询只允许登录且资料完整用户与发起人对话，不能自聊；进行中的活动可咨询，终态已有会话只读，不新建空会话。
- 群聊最小未读先做新消息提示，不虚构精确计数；消息中心须提供群会话入口。咨询继续复用私信列表及聊天页面。
- Memory、Cloud、Mock 同步；测试包括旧 DM 权限回归、非成员/退出/重入、终态/下架、并发幂等、分页、条件已读、资料不完整与账号禁用。
