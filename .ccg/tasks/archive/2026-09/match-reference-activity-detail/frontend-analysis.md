# 前端分析综合（不是实装审查）

来源：用户本轮贴回的 Web Gemini 分析，附件 /Users/cx/.codex/attachments/3c715c54-fc63-4f67-9231-46ab4671ce95/pasted-text.txt。以下为主会话综合，用户明确需求优先。

## 必须修改 / 采纳

- 活动详情改为全宽高幅封面、纯白连续圆角内容区、浅灰信息块、独立圆头像。
- 底栏为群聊、聊下、原生分享、黑底亮绿“加入成团”；群聊必须新增真实多人消息能力，咨询独立创建与发起人的私信。
- 保留角色和生命周期分支，审批提交不能被展示为已加入；所有异步入口同步加锁并隔离离屏响应。
- 底栏主按钮 flex:1/min-width:0，自适应剩余空间；页面为底栏和安全区预留滚动空间。

## 建议修改 / 采纳

- 导航用离散状态切换及 CSS transition，不按滚动帧高频 setData；观察器断开或生命周期清理。
- 封面加载失败有中性占位；使用现有资产作为示意，不声称实拍或还原参考海报内容。
- 已加入、待审批、发起人、终态各有明确 CTA 文案；辅助按钮无障碍名称完整。

## 暂不采纳 / 纠正

- 700rpx 被称为参考实测不成立。参考图显示宽 946px、内容面板顶约 y1536，面板起点约 1218rpx（1536/946*750），约占截图屏高75%。700rpx 在 375px 屏宽仅350px，不能匹配该参考。最终以同尺寸截图的面板起点比例验收，注意系统状态栏是否占布局高度，不重复计入。
- 不采纳为露出时间地点而强制短屏压缩至620rpx：与用户最新要求相反。短屏保证标题在底栏上方可见并允许继续滚动，不要求首屏强塞全部关键信息。
- 320px 设备仍是750rpx宽，不是640rpx；底栏空间必须按真实像素及热区计算。
- 不把返回键56/64rpx、底栏项68/76rpx直接当可点击热区：图形可小，按钮热区仍至少44px。
- 不采纳将群聊指向现有成员空间；不再次询问用户已经确认的真实群聊需求。
- 不添加“免费”、NEW、橙色管理CTA等未确认修饰；无支付不等于活动本身无费用。
- 不新增上传机制、自动生成海报或默认深灰黑主题背景；保留现有示意图，缺少原始素材作为验收限制说明。
