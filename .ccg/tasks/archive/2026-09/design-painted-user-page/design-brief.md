# “我的”页面视觉简报

## 页面层级

1. 沉浸式状态栏与微信胶囊安全区。
2. 个人主页 Header：油画棒头像、昵称、成年状态、编辑入口与一句简介。
3. 三项活动统计：我发起的、我加入的、已成团。
4. 可选待处理纸条：仅有真实未读任务时展示。
5. “我的拼单”区域：我发起的 / 我加入的 / 已成团 / 历史。
6. 奶油白活动卡片流或空状态。
7. 五栏自定义 TabBar，“我的”选中，中央拼图发布按钮无文字。

## 视觉边界

- 深蓝粗纹纸 `#075AA7`。
- 奶油白纸片 `#FFF8EE`。
- 深墨蓝文字 `#102A43`。
- 翡翠绿强调 `#16A36A`。
- 油画棒颗粒、略不规则手绘边缘、轻微纸片投影。
- 不使用写实照片背景、玻璃拟态、体素 3D、粉丝社交指标或校园专属内容。
