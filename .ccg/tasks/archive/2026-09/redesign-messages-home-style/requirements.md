# 消息主页：首页同源视觉更新

## 用户授权与范围

用户正在自行完成高德控制台配置，同时要求消息界面按首页风格设计更新。本任务只覆盖 pages/messages/index 的列表主页与对应规范、验证；独立聊天页、首页、共享 TabBar、后端及高德配置不在范围内。纯前端 M 级任务按 CCG 先取得网页版 Gemini 实际分析，再实施，完成后再审查。

## 当前事实

- 首页背景 #F9F7F2，主文字 #111827，辅助文字 #78716C，白到暖白渐变 Hero、32rpx 圆角、细边框和柔和暖色阴影；快捷卡使用淡橙、浅蓝、浅紫。
- 消息页现有深蓝纸纹、系统通知入口和全部私信列表，已有加载、错误重试、空、分页与分页错误态。
- 会话展示昵称首字受控色盘、昵称、时间、消息摘要、真实未读和可选来源活动；一次加载 20 条。
- 系统通知当前点击最新通知并走白名单路由，无通知时去我的页，不能宣传为通知中心。
- 当前 conversations.length 是已加载数量，不是服务端总量；设计去掉容易误解的总数标签。
- 消息页保留页面滚动、下拉刷新、触底分页和安全区计算；不能移植首页 disableScroll / 固定裁切 / 负偏移。

## 单一设计草案

1. 暖米白背景贯穿页面与原生下拉区，黑色状态栏字；局部移除深蓝背景图与遮罩，不修改全局样式。
2. 紧凑标题区：小标 PINBA MESSAGES，标题“消息”，副文案“和搭子保持联系”。采用首页深色粗标题、少量琥珀色点缀，不新增高幅 Hero 或大插画。
3. 系统通知为浅奶油橙渐变卡片，圆角约 28rpx，复用首页铃铛小图标；保留真实摘要、未读徽标和现有入口。
4. 下接“全部私信”栏目，去掉已加载数量冒充总数；白色会话卡圆角约 24rpx、细暖灰边框、轻阴影、16rpx 间距。
5. 会话主体横向排布头像与消息信息；昵称和时间在窄屏可合理重排，摘要省略，来源作为轻量辅助文字；真实未读红徽标仅在 count > 0 展示。
6. loading / empty / error / loadingMore / loadMoreError 全部使用同源白卡和深色文字；保留错误重试真实事件，纯视觉装饰退出触控和无障碍树。
7. 正文 >= 28rpx，辅助 >= 24rpx，操作热区 >= 44px；底部至少 calc(180rpx + env(safe-area-inset-bottom))，卡片允许随文本增高，320px 窄屏及大字可滚动读取。
8. 不增加搜索、筛选、在线状态、已读回执、群聊入口、统计、批量已读等新功能；不伪造人物消息或未读数。
