# 需求

- 为发现页“成团记忆”专题板生成一张背景图并实际接入。
- 画幅比例沿用模块 `347:430`，适合约 `694 × 860rpx` 的竖向区域。
- 参考图只作为明亮蓝色旅行画报氛围与构图参考，不复制品牌、标识或文字。
- 背景不得包含人物合影、活动照片、点赞、促销或任何可能被误认成真实活动的数据。
- 中部三卡区域必须保持低干扰，确保真实活动卡片和白色文字清晰。
- 交付为 iOS 微信稳定解码的 Baseline JPEG，并提供纯 CSS 渐变降级。

## 本轮补充

- 专题板顶部艺术字严格采用参考图的两行画报排版：第一行白色“分享你的”，第二行黄色“成团”与白色“记忆”组合，并保留倾斜相机线稿。
- 艺术字必须用 WXML/CSS 可控文本实现，不烘焙进位图，避免中文生成错误、模糊及无障碍缺失。
- 晒图区域固定保持参考图的三块拼贴：左侧通高大块，右侧上下两个等高小块。
- 真实成团记录不足三条时不得伪造活动、用户或照片；使用明确的受控空白晒图槽补齐几何版式。
- 三条及以上记录继续展示真实活动内容；点击行为只存在于真实记录，空槽不可点击。
