# 私信页面审查记录

## 分析阶段（网页版 Gemini 3.7 Flash）

- 必须支持连续英文、数字和无空格字符断行。
- 举报入口应位于共同活动纸条右端，不进入微信胶囊所在导航区域。
- 同一发送者 3 分钟内的连续消息隐藏重复头像与时间。
- 建议使用紧凑活动纸条、空状态破冰词、键盘锚点和成员失效只读切换。
- 不采用大型活动卡、在线状态或已读回执。

## 主会话综合与实装

- 已将私信页改为沉浸式自定义导航，复用全站固定拼图纸纹背景。
- 已实现紧凑共同活动条、独立 44px 举报热区、左右手绘纸片气泡和受控单字头像。
- 已新增消息展示装饰层，按发送者与 3 分钟时间窗合并重复头像和时间。
- 已实现长文本断行与文本选择、历史消息局部重试、空状态破冰词、发送失败保留输入、键盘聚焦锚定最新消息和只读态收键盘。
- 共同活动条使用 88rpx 最小高度，以满足举报与查看活动两个入口的 44px 触控要求；视觉内容保持单行紧凑。

- 根因：本机私有配置处于 Cloud 模式，而已部署云函数版本未证明包含最新 `dm.*` 动作；错误发生在会话列表请求阶段，并非聊天路由无法注册。
- 处理：本地视觉预览显式切回 Mock；Mock 默认注入一条已成团羽毛球会话和双方消息，Cloud 失败不自动回退 Mock。
- 已通过开发者工具真实验证：消息中心显示“阿同”会话卡，点击进入具体聊天页并渲染双方气泡与输入栏。
- 最新重新编译后再次验证：具体私信页仍可直接打开，共同活动类型已正确显示为“拼运动”。
- GPT-5.5 后端复审无 Critical；提出 Mock 空数组恢复、前端仅消费 `activityType`、历史活动类型归一化三项建议，均已落实。
