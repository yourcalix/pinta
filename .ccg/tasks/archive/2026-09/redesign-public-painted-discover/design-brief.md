# 发现页设计任务书（审查稿）

## 唯一推荐层级

1. 深蓝纸纹固定背景，正文遵循自定义导航安全区。
2. 紧凑品牌 Header：`拼吧 · 发现`，副标题 `发现附近正在发生的拼单`。
3. 奶油白手绘搜索框：搜索活动、地点或发起人。
4. 横向可滑筛选 Chip：全部 / 拼同行 / 拼运动 / 拼饭桌。
5. 列表标题：默认 `正在组队`，筛选后 `筛选结果`；显示当前已加载数量与清除筛选。
6. 奶油白活动卡片流：类型、状态、标题、时间、地点、人数、发起人、进度与详情提示。
7. Loading / Empty / Error / Load more / End 状态。

## 组件视觉

- 移除当前白绿大 Hero 和 `hero-campus.png`；Header 高度控制在 100–120rpx。
- 背景复用 `publish-paper-texture.webp`，叠加深蓝底色；不使用整页切图。
- 搜索框与活动卡使用奶油白 `#FFF7E8`，深墨蓝正文 `#102A43`。
- 卡片边框用 2rpx 低饱和深蓝或类型色，圆角 24rpx，轻微手绘不规则感通过伪元素和纹理实现。
- 不给列表中每张活动卡放大人物插画，避免重复与性能负担；只用小型类型标记、笔触和原生文字。
- 类型筛选使用 `scroll-view scroll-x`，便于未来扩展。
- Native TabBar 保持不变。

## 实装原则

- 所有业务文字、状态和数字由 WXML 渲染，不烘焙进图片。
- 活动卡继续复用 `activity-card` 组件，不改变 API 数据契约。
- 只改发现页和活动卡视觉层，保留当前 JS 数据流与启动动画状态机。
- 首版不要求新增图片资产；背景直接复用发布页纸纹。若审查认为必须增加装饰，只允许一张小型透明油画棒贴纸。
