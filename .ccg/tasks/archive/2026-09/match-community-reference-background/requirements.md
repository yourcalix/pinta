# 需求

## 用户目标

将“社区”Tab 从当前深蓝纸纹方案继续调整为参考截图的整体观感，要求页面排版与背景尽可能一比一还原。

## 参考图关键特征

- 整页为从顶部暖白、右上柔粉，到中下部浅蓝的柔焦渐变背景，带轻微雾化光斑，不使用当前深蓝纸纹。
- 顶部“拼吧社区”使用深色居中标题。
- 公告条、双快捷卡、栏目区与帖子卡的尺寸、圆角、留白和层级应贴近参考图。
- 帖子流保持白色大圆角卡片，正文为主要视觉内容。

## 数据与交互边界

- 只使用现有社区公开 DTO 的昵称、正文、时间、点赞数和回复数。
- 不伪造参考图里的热门话题、置顶、浏览量、图片宫格或不存在的分类 Tab。
- 保留发帖登录/资料门禁、帖子详情跳转、分页、加载/空/错误状态和自定义 TabBar。
- 新背景必须为本地主包 PNG/JPEG，不包含文字、人物、品牌标志、水印或 UI 元素；优先使用 Baseline JPEG 控制主包体积与 iOS 微信兼容性。

## 验收标准

- 375px 视觉层级、背景色域、模块间距和参考图高度接近。
- 320px 下无文字重叠、横向溢出或触控热区缩水。
- 状态栏、微信胶囊和 TabBar 安全区无重复避让。
- 自动化测试、项目检查和开发者工具编译通过。
