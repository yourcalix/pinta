# 需求

## 目标

- 搭子星球球面节点展示所有曾经完成登录、当前账号仍可公开展示的真实用户。
- 用户首次完成登录后进入球面成员目录，不要求其当前在线。
- 页面底部“当前 X 人在线”只统计当前有效在线 Presence，不使用球面成员总数替代。
- 已登录且账号有效的用户进入小程序前台后自动计入在线 Presence，不再由星球页按钮手动开始。
- 小程序进入后台或退出时停止当前 Presence；TTL 继续作为异常退出兜底。
- 保留点击节点进入对应用户只读公开主页的能力。

## 必须保持

- 不生成假用户、假节点或假在线人数。
- 不向前端公开 openid、userId、位置、联系方式或其他稳定敏感标识。
- 停用、封禁或不可公开账号不得出现在球面目录。
- 在线人数继续由带过期时间的 Presence 权威计算。
- Canvas 动画不得逐帧 `setData`，并继续支持旋转、缩放和点击命中。

## 已确认边界

- Canvas 同屏最多渲染 50 位真实用户；超过 50 位时静默抽样，不展示目录总数或抽样说明。
- 星球页面不再提供手动开始/停止按钮；离开星球页但仍处于小程序前台时继续计为在线。
- 游客、登录失败或停用账号不计入在线；资料未完善的 `ACTIVE` 账号仍计入。
- Presence 会话令牌只保留在 App 级内存闭包中，快速切前后台以 epoch 隔离旧异步响应。
