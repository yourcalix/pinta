# 实施计划：乐聚拼吧活动进程 IP 卡片

## 已批准的一期边界

- 只为 `food` 活动自动展示进程卡。
- 自动触发 `MEAL_REGISTERED / MEAL_TEAM_READY / MEAL_ACTIVE / MEAL_FINISHED`。
- `MEAL_MENU_READY / MEAL_CHECKPOINT` 保留真实素材与配置，仅允许 Mock 开发模式定向预览，不参与生产自动裁决。
- 不接入旅行素材，不把它改名或映射为攀岩；攀岩六阶段等待正确素材和稳定后端 subtype/事件契约。

## 实施顺序

1. 先新增失败测试，覆盖配置注册表、阶段裁决、单阶段跳跃、seen/snooze、身份隔离、组件退场、图片错误及详情页浮层互斥。
2. 将六张不透明拼好饭原图保持完整比例转换为 900×1125 Baseline JPEG；不裁切内容、不修改画面，放入活动分包资源目录。
3. 新增活动分包配置注册表，集中维护六阶段顺序、标题、图片和自动触发资格，并保留未来 subtype 扩展入口。
4. 新增纯函数 resolver，只依据 `type/status/viewerRole/viewerMembership` 裁决四个权威阶段；终止态与非成员返回空。
5. 新增 progress state service，以 API 模块私有 actor scope、活动 ID 和阶段派生不可逆摘要键；实现 seen、5 小时 snooze、最高已收下阶段防倒退和有界存储。
6. 新增分包组件 `leju-progress-card`，实现图片加载门禁、460ms 单次入场、220ms 退场后卸载、克制星点、双 88rpx 操作按钮、关闭按钮、图片失败事件和无障碍聚合。
7. 接入活动详情：首屏数据先正常渲染，再静默确认 actor scope；延迟 450ms、低优先级互斥展示；申请抽屉/集合地点弹窗打开时主动让行；隐藏与卸载清理全部计时器和候选状态。
8. 增加仅在 `useMock === true` 时生效的 `progressCardDebugStage` 本地预览配置，支持六张拼好饭卡逐张验收，生产默认关闭。
9. 跑专项测试、全量测试、语法/结构校验和包体积门禁；检查 Git diff 只包含任务范围。
10. 按 CCG 路由完成 GPT-5.5 契约复审和网页版 Gemini 前端复审，修复 Critical/Warning 后归档任务并提交。

## 明确不做

- 不增加虚假的活动足迹/收藏页面。
- 不新增全局 modal manager；详情页使用局部、可验证的低优先级仲裁。
- 不改写无关品牌字符串，不重构现有活动详情架构。
- 不修改、重绘或裁切 IP 画面。
- 不自动触发缺少后端事实的点单、打卡、装备、检查点阶段。
