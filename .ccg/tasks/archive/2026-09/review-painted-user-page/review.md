# “我的”页面首稿综合评审

## 必须修改

- 压缩顶部 Header、资料与统计的纵向占用，短屏至少露出“我的拼单”首张卡片上半部。
- 不把个人简介加入首期数据模型；当前工程没有 Bio 字段，视觉稿中的简介应删除。
- 长列表不使用左侧大位图插画，继续复用已验收的纯 CSS `activity-card`。
- 四个列表 Tab 使用 `flex: 1`、`min-width: 0` 和单行保护，不改变现有业务文案。
- 待办节点只在有真实未读事项时存在，不保留空白占位。

## 建议修改

- 顶部统计项可与下方列表 Tab 联动，但属于新增交互，不作为首期阻断项。
- 资料卡与统计条可视觉整合，以减少首屏高度。

## 暂不采纳

- 不采用 CSS 单字头像替代个人主页肖像；该方案会削弱已确认视觉稿的个人主页识别度。
- 不新增活动列表插画；长列表继续使用类型色条与文字信息。

## 资产结论

- 复用 `publish-paper-texture.webp` 与现有自定义 TabBar 资产。
- 现有 `avatar-passenger-a/b/empty.png` 是旧体素风，不能直接用于新页面。
- 需要新增 3 张统一画布、透明背景的油画棒头像：男、女、中性占位。
- 昵称、成年状态、统计、待办、列表 Tab 和活动内容全部由 WXML/WXSS 渲染。

## Gemini 反馈

网页版 Gemini 3.7 Flash：无 Critical；主要 Warning 为首屏纵向堆叠、320px Tab 拥挤与条件待办布局跳动。综合后结论为调整后可实装。
