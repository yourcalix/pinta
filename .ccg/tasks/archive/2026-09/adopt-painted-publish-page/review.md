# Web Gemini 前端审查综合

## 必须修改

- 移除顶部搜索框与“推荐/全部”筛选 Chip，避免发布页被误认为发现页。
- 移除底部重复的选中类型详情卡，类型选择只保留横向画廊，一张卡片直接进入对应发布表单。
- 生产代码继续使用 Native TabBar，视觉稿内手绘 TabBar 不作为页面切图。
- 画廊采用横向 `scroll-view`，未来新增模块时直接追加。
- 深蓝背景只承载白色/奶油白标题和奶油白卡片，不直接放中灰正文。

## 建议修改

- 草稿条保留为真实能力，但只在检测到 `pinba_publish_draft_companion / sport / food` 任一有效草稿时展示；点击进入最近保存的对应表单。
- 透明素材只包含三张模块插画和奔跑学生；安全盾牌、胶带、星芒、卡片、文字、按钮与标签由WXML/WXSS实现。
- 页面使用CSS深蓝底色叠加小尺寸低对比纸纹，而不是1024px重图直接铺满主包。

## 暂不采纳

- 不额外生成 `icon-safety-shield.png`、胶带和星芒贴纸，微型光栅资产在24px附近辨识收益低且增加包体与请求复杂度。
- 不保留任何搜索、分类Chip或“当前模块详情”重复交互。

## 已确认事实

- 发布表单已实现按类型隔离的本地草稿保存与成功后清理。
- 内部类型继续为 `companion / sport / food`；用户可见文案统一调整为“拼同行 / 拼运动 / 拼饭桌”。
