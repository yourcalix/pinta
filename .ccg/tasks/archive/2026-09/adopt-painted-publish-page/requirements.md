# 发布页手绘拼贴风替换

- 以用户选定的 Image 2 视觉稿为唯一视觉基准，重构 `miniprogram/pages/publish/`。
- 保留发布门禁、三类活动路由和安全说明逻辑，不变更服务端契约。
- 当前模块统一显示为“拼同行 / 拼运动 / 拼饭桌”；内部类型继续使用 `companion / sport / food`。
- 页面结构支持未来模块横向或纵向追加，不写死三列。
- 图像资产只承担插画和纸张纹理；文字、卡片、搜索、标签、按钮、状态和无障碍语义由 WXML/WXSS 实现。
- 最小资产集：三个透明模块主插画、一个透明奔跑吉祥物、一张可平铺深蓝纸纹。
- 生成稿不得包含文字、按钮、边框、二维码、车辆、司机、运输或支付元素。
- 实施前通过网页版 Gemini 3.7 Flash 完成前端视觉与适配审查。
- 操作顺序固定为：整页视觉稿Gemini审查 → 主会话综合并锁定布局/资产清单 → 逐项生成素材 → 素材QA → WXML/WXSS实装 → 真机截图复审。
- Gemini审查后唯一布局收敛为：紧凑Header → 横向模块画廊（整卡直达）→ 有草稿时显示草稿条 → 轻量安全说明；移除搜索、推荐Chip和重复详情卡。
