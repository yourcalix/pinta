# 社区页首版设计简报

## 页面目标

让用户快速浏览附近/兴趣讨论，并以低干扰入口发起新讨论；保持社区次于“发布拼单”的业务权重。

## 推荐层级

1. 深蓝纸纹沉浸背景。
2. 紧凑标题区：`拼吧 · 社区`、`聊兴趣，也分享互助经验`。
3. 奶油白轻量发帖入口：一句引导文案 + `发起讨论` 按钮，整条不做大型 Hero。
4. `最新讨论` 标题、真实条数。
5. 奶油白高密度帖子卡流：CSS 单字头像、昵称/时间、三行正文、回复数和进入箭头。
6. Loading / Empty / Error / End 状态。

## 视觉约束

- 背景复用 `assets/images/publish/publish-paper-texture.webp`。
- 卡片以 `#FFF8EE` 为主，正文 `#102A43`，品牌绿只用于主操作和局部标识。
- 删除社区页头部与空状态里的旧体素 Tab 图标和固定水印。
- 帖子卡不使用每条图片头像；使用昵称首字的 CSS 圆形占位，减少列表图片解码。
- 发帖入口热区、错误重试按钮不小于 88rpx。
