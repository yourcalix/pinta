# 移除学生认证要求

## 产品变更

- 小程序用户画像从“校园学生”调整为“所有人”。
- 暂时完全移除校园学生认证相关要求；未来如有需要再通过新的产品决策重新引入。

## 目标行为

- 微信登录并具备可用账号的普通用户，可按现有基础资料规则发布和加入活动。
- 发现页与活动详情继续允许游客公开浏览。
- “我的”页面不再展示学生认证入口、状态卡或由认证状态控制的数据锁定卡。
- 发布页、发布表单、活动详情与加入动作不再读取或跳转学生认证。
- 服务端 `activity.create`、申请/加入以及个人活动读取不再要求 `studentVerifications.status === APPROVED`。
- 删除学生认证页面、路由、前端服务动作、Mock 动作与后端 API 动作、验证、存储和配置中的相关实现。
- 删除对应错误码、测试夹具、产品文案与规范残留。

## 保留边界

- 登录、账号状态、成年/基础资料完整性、内容安全、幂等、容量、活动状态和成员权限等其他门禁保持不变。
- 不重新引入司机或车辆功能。
- 已存在的历史学生认证数据不执行生产数据库物理删除；应用代码停止读取与写入，后续数据迁移另行决策。
