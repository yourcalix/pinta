# 需求

公开会合地点必须支持全国搜索，不得把查询城市、候选坐标或行政区限定为澳门。

## 已发现的现状

- 客户端高德搜索固定传入 `city: 澳门` 与 `citylimit: true`。
- 客户端 POI 清洗仅接受澳门坐标，并要求文本检索结果属于澳门行政区。
- Cloud 与 Mock 的会合地点校验同样只接受澳门试点矩形。
- 发布表单把活动 `city/district` 固定写为澳门；即使前端搜到外地地点，也会形成地点与活动行政区不一致。
- `activity.nearby` 当前仍是澳门试点能力，其城市筛选与定位边界需要和“全国发布地点”明确解耦或同步升级。

## 验收目标

- Input Tips 与 `place/text` 均进行全国检索，不携带澳门限定参数。
- 接受全国范围内合法的高德 GCJ-02 POI，同时拒绝无效坐标与明显非中国范围坐标。
- 选点结果携带受控省、市、区展示字段，发布 payload 的 `city/district` 与选中 POI 一致，不再硬编码澳门。
- Cloud、Mock 与前端地点契约同构，外地地点能够成功发布。
- 全国搜索不得泄露 Key、原始高德错误或用户实时位置。
- 明确处理现有“附近”能力：不能让全国地点在列表筛选、附近查询或游标中产生城市错配。
