# 修复真实环境残留学生认证门禁

## 现象

- 手机或开发者工具真实环境进入“我的”页面后，`activity.mine` 或 `notification.list` 请求失败。
- 页面显示旧文案“请先完成校园学生认证”，与当前面向所有成年用户的新模型冲突。

## 已知事实

- 本地小程序运行配置 `useMock: false`，调用真实 CloudBase `api` 云函数。
- 当前仓库服务实现已将学生认证动作标记为下线，创建、申请、我的活动均只依赖登录、账号状态、完整资料与成年确认。
- 全量本地测试覆盖普通成年人无需学生认证访问核心业务。

## 目标

- 查明真实环境是否仍运行旧版 `api` 云函数。
- 将真实 CloudBase 运行代码与仓库当前契约对齐。
- 不使用前端吞错或文案替换掩盖旧后端门禁。
- 部署后回读运行时配置并验证 `auth.login`、`activity.mine`、`notification.list`。
