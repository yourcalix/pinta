# 根因分析

## 结论

- 小程序本地私有运行配置使用 `useMock: false`，当前真实请求指向已配置的 CloudBase 环境与 `api` 云函数。
- 仓库当前 `cloudfunctions/api` 已删除学生认证门禁；本地测试证明普通成年用户无需学生认证即可访问 `activity.mine` 与 `notification.list`。
- 仓库中不存在截图里出现的“请先完成校园学生认证”文案，因此错误来自远端旧版运行代码的概率极高。
- 微信开发者工具 CLI 已确认目标环境存在且 `api` 状态为 Active，运行时为 Nodejs16.13，超时 15 秒。

## GPT-5.5 交叉分析

- 认定最高概率根因为部署中的 `api` 云函数版本陈旧。
- 不应在前端过滤或替换学生认证错误，这会掩盖仍然生效的旧授权门禁。
- 安全修复路径是部署当前仓库云函数，然后验证 `auth.login`、`profile.get`、`activity.mine` 与 `notification.list`，同时确认旧学生认证动作返回 `NOT_FOUND`。

## 当前阻塞

- 云函数部署会修改真实 CloudBase 外部状态，需要用户明确授权后执行。
- 开发者工具 CLI 的函数下载命令返回二维码路径错误，未能下载远端包做文本差异；现有截图、代码检索和接口契约证据已足以支持“远端版本陈旧”的判断。
