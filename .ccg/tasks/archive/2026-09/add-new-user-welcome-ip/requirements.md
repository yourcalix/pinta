# 新用户首次进入随机欢迎 IP

## 用户目标

- 新用户首次进入“乐聚拼吧”微信小程序时展示欢迎 IP。
- 六套欢迎图针对不同用户随机分配。

## 初步约束

- 同一用户的随机结果必须稳定，不能在重进、刷新或弱网重试时换图。
- 欢迎层只消费一次，不得在普通回前台或后续启动中重复打扰。
- 不与现有 App Session 启动加载层、登录流程或深链进入页面发生浮层竞争。
- 保护主包与分包体积预算，源 PNG 不可直接全量进入主包。
- 覆盖 320×568、现代全面屏 iPhone、20:9 Android、安全区与无障碍场景。

## 待分析

- 六张全屏画面的裁切安全区、按钮/关闭交互与图片解码门禁。
- 素材压缩格式、目标尺寸与包归属。

## 已确认的工程事实

- 六张源图均为 `941×1672`、无透明通道的 9:16 纵向 PNG，标题与说明文字已烘焙进画面。
- 六张源图合计约 14.7MB，不能直接放入主包；主包当前约 1.596MiB，仅余约 117KiB。
- 现有首页启动加载层每个 App Session 只展示一次，新用户欢迎层应在启动层退出后再进入，不能叠层。
- 服务端应在新建用户时写入独立的欢迎状态：稳定分配有限枚举 variant，显式记录 `PENDING/SEEN/SKIPPED`。
- `auth.login` 只向前端返回 `campaign/pending/variant`；新增幂等 `welcome.ack` 由当前登录用户确认消费，不接收用户 ID。
- 功能上线前的旧账号不补弹；不能用 `profileComplete` 判断新用户，也不能仅依赖本地 Storage。
