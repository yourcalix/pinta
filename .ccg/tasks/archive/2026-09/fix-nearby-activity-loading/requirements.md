# 附近拼吧加载失败修复需求

## 现象

- 用户已进入“附近拼吧”并完成定位，页面顶部半径与类型筛选正常显示。
- 主体进入通用错误态：“暂时没能加载附近活动 / 附近活动加载失败，请检查网络”。
- 点击“重新定位”仍无法恢复。

## 目标

- 查明失败发生在定位、客户端请求、CloudBase 动作、数据库地理索引或历史数据兼容的哪一层。
- 保持首屏不主动索权、定位坐标不持久化、精确坐标不公开等既有边界。
- 对可恢复的服务不可用给出准确状态，不把索引或服务配置问题误报为普通网络故障。
- 修复后覆盖真实 Cloud 与 Mock 契约、重试、生命周期和错误归类测试。

## 限制

- 不改动附近页现有视觉布局、筛选结构或 TabBar。
- 不伪造附近活动，不把全城活动冒充附近结果。
- 不绕过服务端距离计算或公开精确坐标。
