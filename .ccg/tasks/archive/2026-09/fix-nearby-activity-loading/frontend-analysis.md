# Gemini 3.7 Flash 前端分析

Verdict：`APPROVE_PLAN`

## 关键结论

- 当前核心缺陷是定位已成功但读取失败后仍提供“重新定位”，动作与失败阶段不匹配。
- 有有效 `_viewerLocation` 时必须直接重试 `fetchNearby()`，避免重复调用 `wx.getLocation` 和触发频率限制。
- `NEARBY_UNAVAILABLE`、网络超时/传输失败和通用服务异常应使用不同安全文案。
- 筛选切换、下拉刷新等已有列表场景失败时应保留内容，只给轻提示。
- 坐标继续只存在页面实例；视图只绑定“是否可直接重试”的布尔状态，不得暴露经纬度。

## 必测场景

- 有坐标重试不再次调用定位。
- 三类错误映射准确且不泄露 CloudBase 原始错误。
- `keepContent` 失败保留列表。
- 请求代际守卫继续拦截晚到响应。
