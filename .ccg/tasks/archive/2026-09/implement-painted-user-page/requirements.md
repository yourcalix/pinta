# 油画棒手绘风“我的”页面实装需求

- 沿用深蓝粗纹纸、奶油白纸片、油画棒笔触的现有品牌视觉。
- 接入已确认的女性、男性与默认拼图三张头像；头像只用于个人资料展示，不改变拼车成员头像体系。
- 顶部使用紧凑品牌标题；资料、成年状态、编辑入口和三项统计整合为一张奶油白卡片。
- 无真实个人简介字段时不渲染伪造签名。
- 待处理事项只在真实未读通知存在时展示。
- “我的拼单”保留我发起的、我加入的、已成团、历史四个分组，统计点击需联动列表分组。
- 列表继续复用纯 CSS `activity-card`，不在长列表引入大插画。
- 覆盖 320px、Safe Area、加载、错误、空状态和无障碍语义。
