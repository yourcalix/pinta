# 需求

## 目标

将“我的”页面点击“编辑主页”进入的资料编辑页，按用户提供的两张参考图重构为白灰极简个人资料页：自定义顶部导航、分组标题、白色大圆角资料卡、纵向资料行和固定底部绿色主按钮。

## 真实字段映射

- 个人头像：继续使用性别映射的受控头像，仅展示，不伪造多图上传能力。
- 昵称：保留现有 2—20 字编辑和校验。
- 性别：保留男/女必选和受控头像联动。
- 关于我：映射现有兴趣标签，继续最多 8 项。
- 年龄确认：映射现有 `adultConfirmed`，不得伪造生日字段。
- 城市继续固定为试点城市，不新增位置授权或城市编辑。

## 不新增

不伪造当前项目没有业务契约的生日、MBTI、手机号、常用报名人、用户协议详情、版本号、账号切换和头像上传入口。

## 必须保留

- `next` 回跳逻辑、保存防重、失败保留表单、错误提示和真实服务写入。
- 键盘顶升、Safe Area、44px 触控热区、窄屏适配。
- 首次补资料场景仍能完成昵称、性别和成年确认。
