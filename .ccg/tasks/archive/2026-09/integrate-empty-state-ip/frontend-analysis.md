# Web Gemini 3.7 Flash 前端分析综合

## 必须落实

- 空状态只允许在 `loading === false && !error && items.length === 0` 时出现；刷新和分页失败且已有内容时必须保留原内容，避免空状态抢跑闪烁。
- `empty-network` 只用于首屏无缓存、无内容且请求失败的页面级故障，不替代 Toast、表单错误或加载更多错误。
- “附近拼吧”保持通用组件单主操作：主按钮扩大搜索半径，页面级次要链接查看全城活动。
- 原始 768px 素材不可直接入主包；清理透明冗余与生成残片后，采用 280px、128 色、Floyd–Steinberg 抖动的透明 PNG，并通过清理旧资源守住 1.71MiB 主包预算。

## 建议落实

- 提供 `small / default / large` 三档视觉尺寸，并为 320×568 与系统大字模式收敛插画尺寸和纵向间距。
- 公共讨论无帖子使用 `activity`；我的参与为空使用 `joined`；我的发起、成团、历史使用 `activity`；消息主页与讨论动态使用 `message`。
- 聊天会话内的轻量空提示保持现状，避免大插画滥用。

## 本轮取舍

- 不在通用组件上全局使用 `transform: translateY(-32rpx)`，避免改变页面几何和命中区域；光学上移通过宿主容器内边距与页面布局完成。
- 插画默认作为装饰节点 `aria-hidden`，标题与说明承担完整语义；仅保留兼容的图片无障碍属性能力，不在业务页重复设置。
- 本轮纳入 `favorite.png`，保证六类契约与用户提供的完整 IP 包一致；通过资源清理消化包体。
- 不新增演示路由，直接在真实页面验收。
