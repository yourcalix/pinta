# Requirements

- 首页“琐碎回忆 / 记录第一次成团”快捷卡不再只显示“即将上线” Toast，而是进入一个可见界面。
- 目标界面复用此前完整保留、已经定稿的“成团记忆”专题画报设计，不重新设计视觉母版。
- 保持首页 Hero、其他快捷卡、活动流、搜索、TabBar，以及拼同行/拼运动/拼饭桌等其他页面不变。
- 优先采用独立分包页面承接，避免把 347:430 的长画报重新塞入首页固定单屏骨架。
- 不伪造用户现场照片、故事正文、点赞、作者或浏览量；必须明确区分已成团活动事实与未来 UGC 分享能力。
- 需要覆盖加载、空态、错误态、返回行为、窄屏、安全区和无障碍语义。
- 所有新增图片继续使用已保留的包内稳定格式，并通过主包/分包体积预算与真机静态检查。
- 独立页使用暖米白根背景并为高饱和蓝色画报保留上下左右呼吸空间，避免从首页进入后的视觉断层。
- 画报前增加克制的“故事分享与精选晒图功能正在筹备中”状态说明，避免不可点击空槽被误解为故障。
- 原生导航标题采用“成团记忆”；当前不开放页面分享能力，避免产生已有真实故事可传播的误导。
