# 实施计划

1. 建立关注领域契约与测试骨架：覆盖关注、取消、重复请求、并发、自关注、过期/越权凭据、账号失效、DTO 脱敏与两类主页 UI 静态契约。
2. 后端输入与服务层：新增 `profile.follow.set`，抽取公开主页目标解析，扩展自有/公开主页 DTO。
3. Store：在 MemoryStore 与 CloudStore 增加 `profileFollows`、关系状态读取和双方计数原子更新。
4. Mock：对齐正式 API 的关系状态、计数、凭据校验和业务幂等行为。
5. 公开主页：两套主题展示关注/粉丝统计，增加关注/取消关注、内存锁、乐观更新、服务端校准与失败回滚。
6. “我的”主页：在兴趣简介与活动指标之间加入不可点击的双列社交统计行。
7. 文档与规范：补充集合、权限、索引、部署和事务验收说明；沉淀关注关系安全规范。
8. 运行专项测试、全量测试与静态检查，执行 GPT-5.5 后端审查及网页版 Gemini 前端审查，修复后归档任务并提交。

# 固定边界

- 本期不做关注/粉丝列表、通知、私信、推荐、互相关注或回关。
- 客户端不接收或提交任何稳定用户 ID。
- 不自动重签过期主页凭据；失败后回滚并提示从来源页面重新打开。
- 关注与粉丝数字仅展示，不渲染为按钮、链接或箭头。
