- 状态：视觉方案已完成并通过审查；自 2026-09-07 起不再挂载于首页。

## 未来真实内容契约

- 仅消费独立、受审核的用户故事 DTO；至少应能区分作者公开资料、授权图片、故事正文、关联活动与发布时间。
- 字段和接口以未来后端正式契约为准，本档案不预设 API 名称或存储结构。
- 真实卡片才可点击进入故事详情；空槽和缺失数据不得跳转到活动详情。
- 用户图片必须完成授权、内容安全审核和失败降级；不可复用活动插画冒充现场照片。

## 恢复验收

- 375px 与 320px 下保持 347:430 外框和左右严格等高网格。
- 背景 JPEG 在 iOS/Android 微信真机正常显示，透明叠层无闪白。
- 艺术字、图片与正文具备足够对比度，大字体不裁切关键内容。
- 空态无死链，真实内容不越过隐私、授权和审核边界。
