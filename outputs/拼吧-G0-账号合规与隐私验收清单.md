# 拼吧 G0 账号、合规与隐私验收清单

版本：1.0

日期：2026-08-23

## 1. G0 交付边界

G0 只建立真实账号接入和隐私合规基线，继续使用 `touristappid`、`useMock=true`、空 `cloudEnv` 和空订阅模板列表。真实 CloudBase 集合、云函数部署、生产内容安全和 `useMock=false` 属于 G1。

## 2. 需要在微信后台完成

### 2.1 账号与基础资料

- [ ] 小程序名称、简称、头像、简介和服务范围与“信息撮合工具”定位一致。
- [ ] 确认管理员、开发者和体验成员；移除不再需要的成员权限。
- [ ] 确认首发城市为上海，公开地点只到行政区、商圈或公共会合点。
- [ ] 服务类目与拼车同行、商品凑单、活动搭子三类真实功能一致；如审核反馈限制某一类，先关闭入口，不通过含糊文案规避。

### 2.2 用户协议与隐私保护指引

- [ ] 填写开发者主体、联系渠道、数据保存期限、用户查阅/更正/删除渠道。
- [ ] 说明用户主动填写的信息：昵称、城市、兴趣、活动内容、申请说明、成团后联系方式、取消/退出原因和举报说明。
- [ ] 说明联系方式只在活动成团后向有效成员按需披露，并记录访问审计。
- [ ] 声明剪贴板用途：用户主动点击时帮助复制已经显示的联系信息。
- [ ] 不声明当前未调用的手机号、精确位置、头像、通讯录、相册、麦克风或二维码能力。
- [ ] 用户协议明确：平台不提供支付、担保、运输、司机或线下赔付；违规内容和线下风险可通过举报处置。

### 2.3 其他 G0 依赖

- [ ] 确认微信内容安全接口申请入口和负责人；实际生产启用留到 G1。
- [ ] 提交订阅消息模板申请；模板未获批不阻塞 G0，且不在本轮实现发送。
- [ ] 创建测试与生产 CloudBase 环境并记录负责人；环境 ID 不进入仓库，集合与部署留到 G1。

## 3. 私有 AppID 配置

仓库公共配置保持：

```json
{
  "appid": "touristappid"
}
```

本地接入有两种等价方式：

1. 复制 `project.private.config.example.json` 为被 Git 忽略的 `project.private.config.json`，再替换其中 AppID。
2. 在微信开发者工具“详情 → 基本信息”修改 AppID；工具会把相同字段优先写入私有配置。

验收：

- [ ] `git status` 不出现真实 AppID、环境 ID 或模板 ID。
- [ ] 删除本地私有配置后，项目仍可用 `touristappid` 导入和运行 Mock。
- [ ] 真实 AppID 下可以打开隐私保护指引，且后台声明与代码实际能力一致。

## 4. 隐私交互验收

### 4.1 开发者工具

- [ ] 游客进入发现页和公开详情时不弹隐私授权。
- [ ] 非成员不能进入成团页，也不能通过前端状态伪造读取联系方式。
- [ ] 成员点击“查看联系信息”时只出现线下安全确认；取消后不请求联系信息。
- [ ] 服务端鉴权成功后才显示联系方式和“复制联系信息”。
- [ ] 联系方式文本支持长按选择。
- [ ] 复制失败显示可理解提示，不输出微信或 CloudBase 原始错误。
- [ ] 隐私弹窗关闭前，复制按钮保持处理中，重复点击不创建多个待处理请求。

### 4.2 iOS 与 Android 真机

- [ ] 首次复制触发自定义隐私弹窗。
- [ ] “查看《拼吧小程序隐私保护指引》”可打开官方页面；失败时有提示。
- [ ] 点击“同意并继续”后原复制动作继续，且只出现微信原生复制成功反馈。
- [ ] 点击“暂不同意”只终止复制，联系方式仍显示，返回、举报和其他操作正常。
- [ ] 拒绝后 10 秒内再次点击不会无响应、死循环或重复叠加弹窗。
- [ ] 已同意用户再次复制不重复弹窗。
- [ ] 微信大字号/关怀模式下说明、协议入口和两个按钮不遮挡、不截断。
- [ ] Home Bar 和安卓手势区不遮挡底部按钮。

## 5. 自动化门槛

- [ ] `npm run verify` 全部通过。
- [ ] 隐私监听只注册一次；无活动组件时意外隐私请求会明确失败而不悬挂。
- [ ] 同意、拒绝、组件销毁都能结算微信隐私回调。
- [ ] 成团页只按需挂载一个隐私组件。
- [ ] 公共 AppID 仍为 `touristappid`，CloudBase 环境与订阅模板仍为空。
