# “拼吧”最小 MVP 运行与验收说明

版本：MVP 0.1  
日期：2026-08-23  
技术栈：微信原生小程序 + Mock Service（默认）+ CloudBase 聚合云函数（可切换）

## 1. 当前交付状态

当前仓库可直接导入微信开发者工具并在游客模式运行。2026-08-23 已在微信开发者工具 Stable 2.01.2510250、基础库 3.15.2 中完成编译和关键流程手工验证。

已实现：

- 零登录浏览、关键字搜索和拼车/拼商品/拼搭子筛选。
- 三类活动详情与两步发布表单、本地单份草稿。
- 参与申请、申请撤回、发起者批准/拒绝。
- 批准即自动占位，达到人数后自动成团。
- 成团后有效成员经安全确认解锁联系方式和会合说明。
- 我的发布、我的参与、待处理通知、双身份演示切换。
- 活动取消、退团、完成、举报和举报者本地即时隐藏。
- CloudBase 服务端权限校验、幂等、原子批准、公开 DTO 脱敏、审计和内容安全适配。

## 2. 本地运行

1. 导入项目目录：`/Users/cx/Documents/Codex/2026-08-23/ccg-2`。
2. 项目 AppID 保持 `touristappid`，选择游客模式。
3. 点击“编译”。不需要安装根目录依赖，也不需要启动本地服务器。
4. 首页应显示 3 个活动；底部应显示“发现 / 发布 / 我的”。

如果开发者工具提示 `webapi_getwxaasyncsecinfo:fail`、`wx.operateWXData` 受限或内部 `timeout`，这是 `touristappid` 游客模式无法访问微信账号能力的工具级提示。当前 Mock 模式不会调用微信登录或云函数，不影响页面与业务演示。使用真实 AppID 登录开发者工具后再做云端联调即可消除这类限制。

## 4. 自动化验收

执行：

```bash
npm run verify
```

验收口径：

- 全部 Node 测试通过。
- 所有项目 JSON 可解析。
- 所有 JavaScript 通过 `node --check`。
- WXML 不使用模板内函数调用等不兼容表达式。
- 业务页面不绕过 Service 层直接调用云函数。

最终结果：23 项 Node 测试全部通过；微信开发者工具自动化确认发现页 3 张活动卡、发布分包、联系方式输入、申请备注与同意事件均正常，未捕获页面 exception 或 error log。最终截图见 `outputs/qa-discover-final.png` 与 `outputs/qa-publish-step2-final.png`。

## 6. 最小 MVP 与正式上线的边界

本次“完成”指代码级最小 MVP 可运行、核心业务闭环可验证；不等同于已通过微信审核或已具备商业化运营条件。正式上线需要用户提供或创建真实 AppID、CloudBase 环境、内容安全权限与合规材料，这些都涉及外部账号及生产配置，不在本地 MVP 自动创建范围内。
